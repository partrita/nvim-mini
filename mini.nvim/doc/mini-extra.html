mini.extra 문서

_ ’mini.nvim’의 main 브랜치에서 생성됨 _

mini.extra 추가적인 ‘mini.nvim’ 기능

MIT 라이선스 Copyright (c) 2023 Evgeni Chasnovski

모듈

다른 ‘mini.nvim’ 모듈에 직접 포함하기에는 필수적이지 않지만 유용한 추가 기능들입니다.

주요 기능:

  • mini.pick을 위한 다양한 피커:

    • 내장 진단(MiniExtra.pickers.diagnostic()).

    • 파일 탐색기(MiniExtra.pickers.explorer()).

    • Git 브랜치/커밋/파일/헌크(MiniExtra.pickers.git_hunks() 등).

    • 명령/검색/입력 기록(MiniExtra.pickers.history()).

    • LSP 참조/심볼/기타(MiniExtra.pickers.lsp()).

    • Tree-sitter 노드(MiniExtra.pickers.treesitter()).

    • 그리고 더 많은 기능들. 자세한 내용은 MiniExtra.pickers를 참조하세요.

  • mini.ai를 위한 다양한 텍스트 오브젝트 사양. MiniExtra.gen_ai_spec을 참조하세요.

  • mini.hipatterns를 위한 다양한 하이라이터. MiniExtra.gen_highlighter를 참조하세요.

참고:

  • 이 모듈은 특정 기능에 필요한 ‘mini.nvim’ 모듈(예: 피커의 경우 ‘mini.pick’)만 요구합니다.

설정

이 모듈은 require('mini.extra').setup({})을 통한 설정이 필요합니다 ({}를 원하는 config 테이블로 교체하세요). 이를 통해 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniExtra가 생성됩니다 ( :lua MiniExtra.* 사용).

사용 가능한 설정값은 MiniExtra.config를 참조하세요.

이 모듈에는 런타임 옵션이 없으므로 vim.b.miniextra_config를 사용해도 효과가 없습니다.

비교

  • nvim-telescope/telescope.nvim:

    • MiniExtra.pickers를 사용하면 ’mini.pick’은 내장 피커 측면에서 상당히 대등한 수준입니다.

  • ibhagwan/fzf-lua:

    • ’nvim-telescope/telescope.nvim’과 동일합니다.

gen_ai_spec

MiniExtra.gen_ai_spec

mini.ai 텍스트 오브젝트 사양 생성기

함수 요소를 가진 테이블입니다. 사양을 얻으려면 호출하세요.

MiniAi.setup()의 일부로 사용되도록 설계되었습니다. 예시:

local gen_ai_spec = require('mini.extra').gen_ai_spec
require('mini.ai').setup({
  custom_textobjects = {
    B = gen_ai_spec.buffer(),
    D = gen_ai_spec.diagnostic(),
    I = gen_ai_spec.indent(),
    L = gen_ai_spec.line(),
    N = gen_ai_spec.number(),
  },
})

gen_ai_spec.buffer()

MiniExtra.gen_ai_spec.buffer()

현재 버퍼 텍스트 오브젝트

참고:

  • a 텍스트 오브젝트는 버퍼의 모든 줄을 선택합니다.

  • i 텍스트 오브젝트는 시작과 끝의 빈 줄을 제외한 모든 줄을 선택합니다.

반환

(function) MiniAi-텍스트 오브젝트 사양을 구현하는 함수입니다.

gen_ai_spec.diagnostic()

MiniExtra.gen_ai_spec.diagnostic({severity})

현재 버퍼 진단(diagnostic) 텍스트 오브젝트

참고:

  • a와 i 텍스트 오브젝트 모두 현재 버퍼에 대한 vim.diagnostic.get() 출력을 반환합니다. 이는 MiniAi-텍스트 오브젝트 사양에 맞게 수정되었습니다.

매개변수

{severity} (any) 사용할 심각도(severity)입니다. vim.diagnostic.get()으로 전달됩니다. 기본값: nil (모든 진단 항목 사용).

반환

(function) MiniAi-텍스트 오브젝트 사양을 구현하는 함수입니다.

gen_ai_spec.indent()

MiniExtra.gen_ai_spec.indent()

현재 버퍼 들여쓰기 범위(indent scope) 텍스트 오브젝트

들여쓰기 범위는 다음 속성을 가진 연속된 줄의 집합입니다:

  • 첫 번째 줄 위와 마지막 줄 아래는 비어 있지 않은 줄입니다. 이를 경계(border)라고 부릅니다.

  • 집합 내에 적어도 하나의 비어 있지 않은 줄이 있습니다.

  • 경계 사이의 모든 비어 있지 않은 줄은 어느 경계보다도 엄격하게 더 큰 들여쓰기(‘tabstop’을 존중하는 시각적 앞쪽 공백)를 가집니다.

참고:

  • a 텍스트 오브젝트는 경계를 포함한 범위를 선택합니다.

  • i 텍스트 오브젝트는 범위를 문자 단위(charwise)로 선택합니다.

  • MiniIndentscope.textobject()와의 차이점:

    • 이 텍스트 오브젝트는 i 텍스트 오브젝트의 위아래 빈 줄을 항상 그 일부로 취급하지만, ’mini.indentscope’는 이를 설정할 수 있습니다.

    • 이 텍스트 오브젝트는 감싸고 있지 않은(non-covering) 범위를 선택할 수 있지만, ’mini.indentscope’는 (설계상) 불가능합니다.

    • 이 텍스트 오브젝트 범위 계산은 위에서 아래로만 수행되며 ’mini.indentscope’처럼 양방향으로 수행되지 않습니다. 이는 대부분의 일반적인 시나리오에서 작동하며, 하단 경계의 들여쓰기가 상단보다 클 것으로 예상되는 경우에만 작동하지 않습니다.

반환

(function) MiniAi-텍스트 오브젝트 사양을 구현하는 함수입니다. 버퍼의 모든 들여쓰기 범위를 시작 줄 번호에 따라 오름차순으로 정렬된 지역 배열로 반환합니다.

  • i 텍스트 오브젝트는 시작 들여쓰기 이후의 줄 내용을 선택합니다.

gen_highlighter

MiniExtra.gen_highlighter

mini.hipatterns 하이라이터 생성기

함수 요소를 가진 테이블입니다. 사양을 얻으려면 호출하세요.

MiniHipatterns.setup()의 일부로 사용되도록 설계되었습니다. 예시:

local hi_words = require('mini.extra').gen_highlighter.words
require('mini.hipatterns').setup({
  highlighters = {
    todo = hi_words({ 'TODO', 'Todo', 'todo' }, 'MiniHipatternsTodo'),
  },
})

gen_highlighter.words()

MiniExtra.gen_highlighter.words({words}, {group}, {extmark_opts})

단어 하이라이트

참고:

  • 단어는 영숫자(라틴 문자 또는 숫자)로 시작하고 끝나야 합니다.

  • 단어는 전체가 일치할 때만 하이라이트되며, 더 큰 단어의 일부인 경우는 제외됩니다. 즉, 단어 앞뒤에 영숫자가 없어야 합니다.

매개변수

{words} (table) 하이라이트할 단어 배열입니다. Lua 패턴이 아닌 리터럴로 매칭됩니다.

{group} (string|function) 하이라이터의 group 필드입니다. MiniHipatterns.config를 참조하세요.

{extmark_opts} (any) 하이라이터의 extmark_opts 필드입니다. MiniHipatterns.config를 참조하세요.

pickers

MiniExtra.pickers

mini.pick 피커

‘mini.pick’ 피커(필수 의존성)를 포함하는 테이블입니다. 참고:

  • 모든 피커는 동일한 시그니처를 가집니다:

    • <local_opts> - 피커 로컬 옵션을 포함하는 선택적 테이블입니다.

    • <opts> - MiniPick.start()로 전달되는 선택적 옵션 테이블입니다.

  • MiniExtra.setup() 또는 MiniPick.setup() 중 하나만 호출해도 MiniPick.registry에 자동으로 등록됩니다.

  • 별도의 언급이 없는 한 모든 피커는 MiniPick-source.preview, MiniPick-source.choose, MiniPick-source.choose_marked의 기본 버전을 사용합니다. 표시되는 텍스트와 MiniPick-source.show는 선택된 항목에 맞춰집니다.

사용 예시:

  • Lua 코드: MiniExtra.pickers.buf_lines().

  • :Pick 명령 사용: :Pick buf_lines scope='current' 참고: 이를 위해서는 MiniExtra.setup() 호출이 필요합니다.

pickers.buf_lines()

MiniExtra.pickers.buf_lines({local_opts}, {opts})

버퍼 줄(lines) 피커

버퍼의 줄 중에서 선택합니다. 참고:

  • 현재 로드되지 않은 모든 대상 버퍼를 로드합니다.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <scope> (string) - “all” (나열된 일반 버퍼들) 또는 “current” 중 하나입니다. 기본값: “all”.

  • <preserve_order> (boolean) - 쿼리 중에 원래 순서를 유지할지 여부입니다. 기본값: false.

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(any) 호출된 피커의 출력입니다.

pickers.colorschemes()

MiniExtra.pickers.colorschemes({local_opts}, {opts})

컬러 스킴(color scheme) 피커

컬러 스킴을 선택하고 적용합니다. 미리보기는 항목의 컬러 스킴을 일시적으로 적용하고 선택된 하이라이트 그룹이 어떻게 보이는지 보여줍니다. 취소하면 피커 시작 전의 컬러 스킴으로 돌아갑니다:

  • mini.colors가 사용 가능한 경우 MiniColors-colorscheme:apply()를 사용합니다.

  • g:colors_name이 사용 가능한 경우 :colorscheme을 사용합니다.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <names> (table) - 선택할 컬러 스킴 이름 배열입니다. 기본값: 사용 가능한 모든 컬러 스킴.

  • <preview_hl_groups> (table) - 미리보기 창에 표시할 하이라이트 그룹 배열입니다. 기본값: 정의된 모든 하이라이트 그룹을 알파벳 순으로 표시.

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(any) 호출된 피커의 출력입니다.

pickers.commands()

MiniExtra.pickers.commands({local_opts}, {opts})

Neovim 명령 피커

Neovim 내장 명령(Ex-commands) 및 사용자 정의 명령 중에서 선택합니다. 참고:

  • 미리보기는 명령에 대한 정보(가능한 경우)를 보여줍니다.

  • 선택하면 명령을 직접 실행하거나(인자가 필요 없다고 판단되는 경우), 명령줄에 해당 명령을 입력합니다.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 현재는 사용되지 않습니다.

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(any) 호출된 피커의 출력입니다.

pickers.diagnostic()

MiniExtra.pickers.diagnostic({local_opts}, {opts})

내장 진단 피커

vim.diagnostic.get()을 사용하여 vim.diagnostic에서 진단 항목을 선택합니다.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <get_opts> (table) - vim.diagnostic.get()을 위한 옵션입니다. 심각도나 네임스페이스를 제한하는 데 사용할 수 있습니다. 기본값: {}.

  • <scope> (string) - “all” (사용 가능한 전체) 또는 “current” (버퍼) 중 하나입니다. 기본값: “all”.

  • <sort_by> (string) - 정렬 우선순위입니다. “severity”, “path”, “none” 중 하나입니다. 기본값: “severity”.

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(any) 호출된 피커의 출력입니다.

pickers.explorer()

MiniExtra.pickers.explorer({local_opts}, {opts})

파일 탐색기 피커

파일 시스템을 탐색하고 파일을 엽니다. 참고:

  • 디렉토리를 선택하면 그 안으로 이동하여 피커의 항목과 현재 작업 디렉토리를 변경합니다.

  • 쿼리와 미리보기는 평소와 같이 작동합니다 ( move_next/move_prev만 사용할 수 있는 것은 아님).

  • 미리보기는 모든 항목에 대해 작동합니다.

예시:

  • MiniExtra.pickers.explorer()

  • :Pick explorer cwd='..' - 부모 디렉토리에서 탐색기를 엽니다.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <cwd> (string) - 탐색을 시작할 초기 디렉토리입니다. 유효한 디렉토리 경로여야 합니다. 기본값: nil (현재 디렉토리).

pickers.visit_paths()

MiniExtra.pickers.visit_paths({local_opts}, {opts})

‘mini.visits’ 방문 경로 피커

MiniVisits.list_paths()를 사용하여 mini.visits에서 경로를 선택합니다. 참고:

  • ’mini.visits’가 필요합니다.

예시:

  • MiniExtra.pickers.visit_paths() - 현재 디렉토리에 등록되고 “최신 빈도수(robust frecency)” 순으로 정렬된 방문 기록.

  • :Pick visit_paths cwd='' recency_weight=1 filter='core' - “core” 레이블이 있는 모든 방문 기록을 최신 순으로 정렬.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <cwd> (string) - MiniVisits.list_paths()로 전달됩니다. 기본값: nil (현재 디렉토리에 등록된 경로를 가져옴).

  • <filter> (function|string) - MiniVisits.list_paths()로 전달됩니다. 기본값: nil (모든 경로 사용).

  • <preserve_order> (boolean) - 쿼리 중에 원래 순서를 유지할지 여부입니다. 기본값: false.

  • <recency_weight> (number) - MiniVisits.gen_sort.default()로 전달됩니다. 기본값: 0.5 (“최신 빈도수(robust frecency)” 정렬 사용).

  • <sort> (function) - MiniVisits.list_paths()로 전달됩니다. 기본값: nil (“최신 빈도수” 사용). 참고: 제공된 경우 recency_weight보다 우선합니다.

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(any) 호출된 피커의 출력입니다.

pickers.visit_labels()

MiniExtra.pickers.visit_labels({local_opts}, {opts})

‘mini.visits’ 방문 레이블 피커

MiniVisits.list_labels() 및 MiniVisits.list_paths()를 사용하여 mini.visits에서 레이블을 선택합니다. 참고:

  • ’mini.visits’가 필요합니다.

  • 미리보기는 미리 본 레이블을 가진 방문 경로로 필터링하여 보여줍니다.

  • 선택하면 본질적으로 선택된 레이블을 가진 경로에 대해 MiniExtra.pickers.visit_paths()를 시작합니다.

예시:

  • MiniExtra.pickers.visit_labels() - 현재 디렉토리에 등록된 방문 기록의 레이블.

  • :Pick visit_labels cwd='' - 모든 방문 기록의 레이블.

매개변수

{local_opts} (table|nil) 이 특정 피커의 동작을 정의하는 옵션입니다. 가능한 필드:

  • <cwd> (string) - MiniVisits.list_labels()로 전달됩니다. 기본값: nil (현재 디렉토리에 등록된 방문 기록에서 레이블을 가져옴).

  • <filter> (function|string) - MiniVisits.list_labels()로 전달됩니다. 기본값: nil (모든 방문 기록 사용).

  • <path> (string) - MiniVisits.list_labels()로 전달됩니다. 기본값: "" (대상 cwd에 대한 모든 방문 기록에서 레이블을 가져옴).

  • <sort> (function) - 미리보기 및 선택을 위해 MiniVisits.list_paths()로 전달됩니다. 기본값: nil (“최신 빈도수” 사용).

{opts} (table|nil) MiniPick.start()로 전달되는 옵션입니다.

반환

(...) 선택된 경로입니다.
