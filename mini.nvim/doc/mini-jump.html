mini.jump 문서

’mini.nvim’의 main 브랜치에서 생성됨

mini.jump 다음/이전 단일 문자로 점프

MIT 라이선스 Copyright (c) 2021 Evgeni Chasnovski, Adam Blažek

모듈

기능:

  • f, F, t, T가 여러 줄에서 작동하도록 확장합니다.

  • f, F, t, T를 다시 눌러 점프를 반복할 수 있습니다. 점프하지 않아서 커서가 이동했거나 유휴 시간(사용자 정의 가능) 후 타임아웃이 발생하면 재설정됩니다.

  • 모든 가능한 대상 문자를 (사용자 정의 가능한 지연 시간 후) 강조 표시하고, 일정 유휴 시간 후 중지합니다.

  • 일반(Normal), 비주얼(Visual), 오퍼레이터 대기(Operator-pending, 순정 Neovim과 동일한 점 반복 지원) 모드를 지원합니다.

이 모듈은 Vim의 ‘ignorecase’ 및 ‘smartcase’ 옵션을 따릅니다. ’ignorecase’가 설정된 경우 f, F, t, T는 대소문자를 구분하지 않고 일치하는 항목을 찾습니다. ’smartcase’도 설정된 경우 f, F, t, T는 소문자만 대소문자 구분 없이 일치하는 항목을 찾습니다.

설정

이 모듈은 require('mini.jump').setup({})으로 설정이 필요합니다 ({}를 사용자 config 테이블로 교체하세요). 이는 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniJump를 생성합니다 (:lua MiniJump.*로 사용 가능).

config 구조 및 기본값은 MiniJump.config를 참조하세요.

런타임 설정을 vim.b.minijump_config를 사용하여 버퍼별로 재정의할 수 있으며, 이는 MiniJump.config와 동일한 구조여야 합니다. 자세한 내용은 mini.nvim-buffer-local-config를 참조하세요.

모듈이 오류가 아닌 피드백을 표시하지 않게 하려면 config.silent = true로 설정하세요.

하이라이트 그룹

  • MiniJump - 모든 가능한 커서 위치.

하이라이트 그룹을 변경하려면 nvim_set_hl()을 사용하여 직접 설정하세요.

비활성화

핵심 기능을 비활성화하려면 vim.g.minijump_disable(전역) 또는 vim.b.minijump_disable(버퍼별)을 true로 설정하세요. 다양한 시나리오와 사용자 정의 의도를 고려하여 모듈 기능 비활성화를 위한 정확한 규칙 작성은 사용자의 몫으로 남겨둡니다. 일반적인 방법은 mini.nvim-disabling-recipes를 참조하세요.

이벤트

사용자 정의 및 외부 도구와의 통합을 위해, 일반적인 상황에서 특정 User 자동 명령 이벤트가 트리거됩니다.

  • MiniJumpGetTarget - 사용자에게 대상을 묻기 전. 예정된 점프에 대한 자세한 정보는 MiniJump.state를 참조하세요.

  • MiniJumpStart - 점프가 시작된 후.

  • MiniJumpJump - 점프를 수행한 후.

  • MiniJumpStop - 점프가 중지된 후.

setup()

MiniJump.setup({config})

모듈 설정

매개변수

{config} (table|nil) 모듈 설정 테이블. MiniJump.config를 참조하세요.

사용법

require('mini.jump').setup() -- 기본 설정 사용
-- 또는
require('mini.jump').setup({}) -- {}를 사용자 설정 테이블로 교체

config

MiniJump.config

기본값

MiniJump.config = {
  -- 모듈 매핑. 비활성화하려면 `''`(빈 문자열)을 사용하세요.
  mappings = {
    forward = 'f',
    backward = 'F',
    forward_till = 't',
    backward_till = 'T',
    repeat_jump = ';',
  },

  -- 다양한 기능에 대한 지연 시간(ms). 사실상 비활성화하려면
  -- 매우 큰 숫자(예: 10^7)로 설정하세요.
  delay = {
    -- 점프와 모든 가능한 점프 강조 표시 사이의 지연 시간
    highlight = 250,

    -- 점프와 유휴 상태(점프가 수행되지 않음) 시 자동 중지 사이의 지연 시간
    idle_stop = 10000000,
  },

  -- 오류가 아닌 피드백 표시 비활성화 여부
  -- 이는 사용자 입력이 필요한 경우 유휴 시간 후 표시되는 (정보 제공용) 도움말 메시지에도 영향을 미칩니다.
  silent = false,
}

state

MiniJump.state

점프 상태 데이터

이 모듈에서 사용되는 다양한 정보를 저장합니다. jumping을 제외한 모든 요소는 최신 점프에 관한 것입니다. 이들은 유사한 인수의 기본값으로 사용됩니다.

사용법

상태에 의존하는 매핑을 정의하는 데 사용할 수 있습니다. 독립형 매핑이거나 MiniKeymap.map_multistep()의 일부일 수 있습니다. 예시:

-- `<Esc>`를 누르면 점프 중지
local jump_stop = function()
  if not MiniJump.state.jumping then return '<Esc>' end
  MiniJump.stop_jumping()
end
local opts = { expr = true, desc = '점프 중지' }
vim.keymap.set({ 'n', 'x', 'o' }, '<Esc>', jump_stop, opts)

클래스

{JumpingState}

필드

{target} (string|nil) 점프할 문자열.

{backward} (boolean|nil) 뒤로 점프할지 여부.

{till} (boolean|nil) 대상에 정확히 위치하는 대신 일치하는 항목 바로 앞/뒤로 점프할지 여부. 여기에는 이전/현재 줄의 끝 너머에 커서를 위치시키는 것도 포함됩니다. 뒤로 점프할 때 줄 너머에 위치시킬 수 없는 경우 커서가 대상에 위치할 수 있습니다.

{n_times} (number|nil) 연속 점프를 수행할 횟수.

{mode} (string) 최신 점프의 모드(인수가 0이 아닌 mode()의 출력).

{jumping} (boolean) 모듈이 현재 “점프 모드”인지 여부. MiniJump.smart_jump() 및 모든 매핑 사용 시 대상 입력이 필요하지 않습니다.

초기값:

MiniJump.state = {
  target = nil,
  backward = false,
  till = false,
  n_times = 1,
  mode = nil,
  jumping = false,
}

jump()

MiniJump.jump({target}, {backward}, {till}, {n_times})

대상으로 점프

문자열을 받아 원하는 방향으로 처음 나타나는 위치로 점프합니다.

모든 기본값은 최신 점프를 모방하기 위해 MiniJump.state에서 가져옵니다.

매개변수

{target} (string|nil) 점프할 문자열.

{backward} (boolean|nil) 뒤로 점프할지 여부.

{till} (boolean|nil) 대상에 정확히 위치하는 대신 일치하는 항목 바로 앞/뒤로 점프할지 여부. 여기에는 이전/현재 줄의 끝 너머에 커서를 위치시키는 것도 포함됩니다. 뒤로 점프할 때 줄 너머에 위치시킬 수 없는 경우 커서가 대상에 위치할 수 있습니다.

{n_times} (number|nil) 연속 점프를 수행할 횟수.

smart_jump()

MiniJump.smart_jump({backward}, {till})

스마트 점프 수행

마지막 이동이 점프였다면 동일한 대상으로 다른 점프를 수행합니다. 그렇지 않으면 (getcharstr()을 통해) 대상 입력을 기다립니다. v:count를 존중합니다.

모든 기본값은 최신 점프를 모방하기 위해 MiniJump.state에서 가져옵니다.

매개변수

{backward} (boolean|nil) 뒤로 점프할지 여부.

{till} (boolean|nil) 대상에 정확히 위치하는 대신 일치하는 항목 바로 앞/뒤로 점프할지 여부. 여기에는 이전/현재 줄의 끝 너머에 커서를 위치시키는 것도 포함됩니다. 뒤로 점프할 때 줄 너머에 위치시킬 수 없는 경우 커서가 대상에 위치할 수 있습니다.

stop_jumping()

MiniJump.stop_jumping()

점프 중지

강조 표시(있는 경우)를 제거하고 다음 스마트 점프 시 대상을 묻도록 강제합니다. 적절한 Neovim 이벤트 발생 시 자동으로 호출됩니다.
