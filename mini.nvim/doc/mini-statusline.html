mini.statusline 문서

mini.nvim의 main 브랜치에서 생성됨

mini.statusline 상태줄

MIT 라이선스 Copyright (c) 2021 Evgeni Chasnovski

모듈

기능:

  • 활성 및 비활성 창에 대한 사용자 정의 상태줄 구조 정의. 이 작업은 ‘statusline’에 적합한 문자열을 반환해야 하는 함수로 수행됩니다. 해당 코드는 다음과 같은 구조의 기본 코드와 유사해야 합니다:

    • 표시하려는 모든 섹션에 대한 문자열 데이터를 계산합니다.

    • MiniStatusline.combine_groups()를 사용하여 그룹으로 결합합니다.

  • 색상이 포함된 내장 활성 모드 표시기.

  • 창이 너무 좁을 때 섹션에서 정보를 숨길 수 있음(특정 창 너비는 섹션별로 구성 가능).

의존성

권장 의존성 (추가 기능을 제공하며, 없어도 작동합니다):

  • Nerd 폰트 (추가 아이콘 지원용).

  • MiniStatusline.section_fileinfo()를 위한 활성화된 mini.icons 모듈. 설정되어 있지 않으면 ‘nvim-tree/nvim-web-devicons’ 플러그인을 사용하거나 아무것도 표시하지 않습니다.

  • MiniStatusline.section_git()를 위한 활성화된 mini.git 모듈. 설정되어 있지 않으면 ‘lewis6991/gitsigns.nvim’ 플러그인을 사용하거나 아무것도 표시하지 않습니다.

  • MiniStatusline.section_diff()를 위한 활성화된 mini.diff 모듈. 설정되어 있지 않으면 ‘lewis6991/gitsigns.nvim’ 플러그인을 사용하거나 아무것도 표시하지 않습니다.

설정

이 모듈은 require('mini.statusline').setup({})으로 설정이 필요합니다 ({}를 config 테이블로 교체하세요). 그러면 스크립팅이나 수동으로(:lua MiniStatusline.* 사용) 사용할 수 있는 전역 Lua 테이블 MiniStatusline이 생성됩니다.

config 구조 및 기본값은 MiniStatusline.config를 참조하세요. 일부 내용 예시는 MiniStatusline-example-content를 참조하세요.

MiniStatusline.config와 동일한 구조를 가져야 하는 vim.b.ministatusline_config 내부 버퍼에 로컬로 런타임 설정 설정을 재정의할 수 있습니다. 자세한 내용은 mini.nvim-buffer-local-config를 참조하세요.

하이라이트 그룹

모드에 따른 하이라이트 (두 번째 MiniStatusline.section_mode() 출력):

  • MiniStatuslineModeNormal - 일반(Normal) 모드.

  • MiniStatuslineModeInsert - 입력(Insert) 모드.

  • MiniStatuslineModeVisual - 비주얼(Visual) 모드.

  • MiniStatuslineModeReplace - 교체(Replace) 모드.

  • MiniStatuslineModeCommand - 명령(Command) 모드.

  • MiniStatuslineModeOther - 기타 모드 (터미널 등).

기본 상태줄에서 사용되는 하이라이트:

  • MiniStatuslineDevinfo - “개발 정보” 그룹용 (MiniStatusline.section_git() 및 MiniStatusline.section_diagnostics()).

  • MiniStatuslineFilename - MiniStatusline.section_filename() 섹션용.

  • MiniStatuslineFileinfo - MiniStatusline.section_fileinfo() 섹션용.

기타 그룹:

  • MiniStatuslineInactive - 포커스되지 않은 창의 하이라이트.

하이라이트 그룹을 변경하려면 nvim_set_hl()로 직접 설정하세요.

비활성화

비활성화하려면(빈 상태줄 표시), vim.g.ministatusline_disable(전역) 또는 vim.b.ministatusline_disable(버퍼용)을 true로 설정하세요. 다양한 시나리오와 사용자 정의 의도를 고려하여, 모듈 기능 비활성화를 위한 정확한 규칙 작성은 사용자의 몫으로 남겨둡니다. 일반적인 방법은 mini.nvim-disabling-recipes를 참조하세요.

기본 내용

이 함수는 활성 내용의 기본값으로 사용됩니다:

function()
  local mode, mode_hl = MiniStatusline.section_mode({ trunc_width = 120 })
  local git           = MiniStatusline.section_git({ trunc_width = 40 })
  local diff          = MiniStatusline.section_diff({ trunc_width = 75 })
  local diagnostics   = MiniStatusline.section_diagnostics({ trunc_width = 75 })
  local lsp           = MiniStatusline.section_lsp({ trunc_width = 75 })
  local filename      = MiniStatusline.section_filename({ trunc_width = 140 })
  local fileinfo      = MiniStatusline.section_fileinfo({ trunc_width = 120 })
  local location      = MiniStatusline.section_location({ trunc_width = 75 })
  local search        = MiniStatusline.section_searchcount({ trunc_width = 75 })

  return MiniStatusline.combine_groups({
    { hl = mode_hl,                  strings = { mode } },
    { hl = 'MiniStatuslineDevinfo',  strings = { git, diff, diagnostics, lsp } },
    '%<', -- 일반적인 잘림 지점 표시
    { hl = 'MiniStatuslineFilename', strings = { filename } },
    '%=', -- 왼쪽 정렬 종료
    { hl = 'MiniStatuslineFileinfo', strings = { fileinfo } },
    { hl = mode_hl,                  strings = { search, location } },
  })
end

불리언 옵션 표시

불리언 옵션에 대한 섹션 문자열을 계산하려면 내용 함수 내부에서 이 코드 스니펫의 변형을 사용하세요 (옵션 자체, 잘림 너비, 짧고 긴 표시 이름을 수정할 수 있습니다):

local spell = vim.wo.spell and (MiniStatusline.is_truncated(120) and 'S' or 'SPELL') or ''

여기서 x and y or z는 삼항 연산자를 수행하는 일반적인 Lua 방식입니다. x가 true이면 y를 반환하고, 그렇지 않으면 z를 반환합니다.

섹션 그룹 결합

각 그룹은 문자열이거나 hl(그룹의 하이라이트 그룹) 및 strings(섹션을 나타내는 문자열) 필드가 있는 테이블일 수 있습니다.

이 함수의 일반적인 개념은 다음과 같습니다;

  • 문자열 그룹은 그대로 사용됩니다 (%< 또는 %=와 같은 특수 문자열에 유용함).

  • 각 테이블 그룹은 hl 필드에 자체 하이라이트가 있고 (없는 경우 이전 항목이 사용됨) strings 필드에 문자열 부분이 있습니다. strings의 비어 있지 않은 문자열은 공백 하나로 구분됩니다. 비어 있지 않은 그룹은 공백 두 개(각 하이라이트에 하나씩)로 구분됩니다.

매개변수

{groups} (table) 그룹 배열.

반환값

(string) ’statusline’에 적합한 문자열.

is_truncated()

MiniStatusline.is_truncated({trunc_width})

잘라내기 여부 결정

이 함수는 기본적으로 창 너비를 계산하고 이를 trunc_width와 비교합니다. 창이 더 작으면 잘라내고, 그렇지 않으면 잘라내지 않습니다. 기본적으로는 잘라내지 않습니다.

섹션에 잘라내기가 필요한지 여부를 수동으로 결정할 때 이를 사용하세요.

매개변수

{trunc_width} (number|nil) 잘라내기 너비. nil인 경우 출력은 false입니다.

반환값

(boolean) 잘라내기 여부.

section_git()

MiniStatusline.section_git({args})

Git 정보용 섹션

mini.git의 Git 요약을 표시합니다 (설정되어 있어야 하며 권장됩니다). 표시되는 데이터의 서식을 조정하려면 MiniGit-examples에 설명된 대로 버퍼 로컬 요약 문자열을 직접 수정하세요.

‘mini.git’이 설정되어 있지 않으면 섹션은 ’lewis6991/gitsigns’ 데이터를 사용하거나 빈 문자열을 표시합니다.

창 너비가 args.trunc_width보다 낮으면 빈 문자열이 반환됩니다.

매개변수

{args} (table) 섹션 인수. args.icon을 사용하여 나만의 아이콘을 제공하세요.

반환값

(string) 섹션 문자열.

‘mini.diff’가 설정되어 있지 않으면 섹션은 ’lewis6991/gitsigns’ 데이터를 사용하거나 빈 문자열을 표시합니다.

section_diagnostics()

MiniStatusline.section_diagnostics({args})

Neovim 내장 진단용 섹션

진단이 비활성화되어 있거나, 설정된 진단이 없거나, 출력이 짧은 경우 아무것도 표시하지 않습니다. 그렇지 않으면 vim.diagnostic.get()을 사용하여 오류(‘E’), 경고(‘W’), 정보(‘I’) 및 힌트(‘H’)의 수를 계산하고 표시합니다.

창 너비가 args.trunc_width보다 낮으면 짧은 출력이 반환됩니다.

매개변수

{args} (table) 섹션 인수. args.icon을 사용하여 나만의 아이콘을 제공하세요. args.signs를 사용하여 심각도 수준 이름별로 사용자 지정 기호를 사용하세요. 예:

{ ERROR = '!', WARN = '?', INFO = '@', HINT = '*' }

반환값

(string) 섹션 문자열.

section_fileinfo()

MiniStatusline.section_fileinfo({args})

파일 정보용 섹션

‘filetype’, ‘fileencoding’ / ‘encoding’, ‘fileformat’ 및 버퍼 크기를 표시합니다. 짧은 출력은 비어 있지 않은 ’filetype’만 가지며, 창 너비가 args.trunc_width보다 낮거나 버퍼가 일반적이지 않은 경우(’buftype’에 따름) 반환됩니다.

버퍼 크기는 파일의 저장된 버전이 아니라 현재 텍스트를 기반으로 계산됩니다.

config.use_icons가 true이고 아이콘 공급자가 있는 경우(mini.statusline의 “의존성” 섹션 참조), 파일 형식 근처에 아이콘을 표시합니다.

MiniStatusline.section_location({args})

버퍼 내부 위치용 섹션

다음 형식으로 버퍼 내부 위치를 표시합니다:

  • 일반: '<커서 행>|<전체 행>│<커서 열>|<전체 열>'

  • 짧게: '<커서 행>│<커서 열>'

창 너비가 args.trunc_width보다 낮으면 짧은 출력이 반환됩니다.

section_searchcount()

MiniStatusline.section_searchcount({args})

현재 검색 횟수용 섹션

searchcount()의 현재 상태를 표시합니다. 창 너비가 args.trunc_width보다 낮거나, 검색 하이라이트가 켜져 있지 않거나(v:hlsearch 참조), 검색 결과 수가 0이면 빈 출력이 반환됩니다.

args.options는 searchcount()로 전달됩니다. 기본적으로 매 호출마다 데이터를 다시 계산하므로 계산 비용이 많이 들 수 있습니다(보통 여전히 0.1ms 수준이지만). 이를 방지하려면 args.options = { recompute = false }를 제공하세요.

매개변수

{args} (table) 섹션 인수.

반환값

(string) 섹션 문자열.
