mini.splitjoin 문서

이 문서는 ’mini.nvim’의 main 브랜치에서 생성되었습니다.

mini.splitjoin 인자 분할 및 결합

MIT 라이선스 Copyright (c) 2023 Evgeni Chasnovski

모듈

기능:

  • 커서 아래의 인자(허용된 구분자 사이의 괄호 내부 영역)를 수정하는 매핑 및 Lua 함수입니다.

    지원되는 동작:

    • 토글(Toggle) - 인자가 한 줄에 있으면 분할하고, 그렇지 않으면 결합합니다. 모듈의 주요 지원 함수입니다. MiniSplitjoin.toggle()을 참조하세요.

    • 분할(Split) - 모든 인자 구분자가 별도의 줄 끝에 오도록 합니다. MiniSplitjoin.split()을 참조하세요.

    • 결합(Join) - 모든 인자가 한 줄에 오도록 합니다. MiniSplitjoin.join()을 참조하세요.

  • 매핑은 일반 모드에서 점 반복이 가능하며 비주얼 모드에서도 작동합니다.

  • 사용자 정의 가능한 인자 탐지 (MiniSplitjoin.config.detect 참조):

    • 인자를 포함할 수 있는 괄호.

    • 인자를 구분할 수 있는 문자열.

    • 구분자를 찾을 때 제외되는 영역 (중첩된 괄호나 따옴표 내부 등).

  • 분할 및 결합 모두에 대해 사용자 정의 가능한 사전(pre) 및 사후(post) 훅. MiniSplitjoin.config의 split 및 join을 참조하세요. MiniSplitjoin.gen_hook에 여러 내장 훅이 있습니다.

  • 수정된 들여쓰기 개념을 사용하여 주석 내에서도 작동합니다. MiniSplitjoin.get_indent_part()를 참조하세요.

  • 특정 위치에서 분할 및 결합을 위한 저수준 Lua 함수를 제공합니다. MiniSplitjoin.split_at() 및 MiniSplitjoin.join_at()을 참조하세요.

참고:

  • 인자 검색은 Lua 패턴(정규식과 유사한 방식)을 사용하여 수행됩니다. 어느 정도의 오탐이 발생할 수 있습니다.

  • 이 모듈은 주로 MiniSplitjoin.toggle()을 중심으로 설계되었습니다. 대상 분할 위치가 서로 다른 줄에 있는 경우, 먼저 결합한 다음 분할하세요.

  • 비주얼 모드 선택 영역에서 동작을 수행할 수 있으며, 이는 주로 초기 영역 탐지가 잘못된 경우의 안전책으로 제공됩니다. 선택 영역을 전체 괄호로 취급하는 MiniSplitjoin.get_visual_region()을 사용합니다 (선택 영역에 괄호 포함).

설정

이 모듈은 require('mini.splitjoin').setup({})으로 설정이 필요합니다 ({}를 config 테이블로 교체하세요). 이는 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniSplitjoin을 생성합니다 (예: :lua MiniSplitjoin.*).

사용 가능한 설정값은 MiniSplitjoin.config를 참조하세요.

런타임 설정(예: 동작 훅)을 MiniSplitjoin.config와 동일한 구조를 가져야 하는 vim.b.minisplitjoin_config를 통해 버퍼 로컬에서 재정의할 수 있습니다. 자세한 내용은 mini.nvim-buffer-local-config를 참조하세요.

비교

  • FooSoft/vim-argwrap:

    • 이 모듈과 디자인이 거의 동일합니다.

    • 주석 내에서 작동하지 않지만, 이 모듈은 작동합니다.

    • 분할 및 결합을 제어하는 더 많은 내장 방법을 제공하는 반면, 이 모듈은 의도적으로 몇 가지만 제공합니다.

  • AndrewRadev/splitjoin.vim:

    • 언어에 의존적인 변환에 더 중점을 두는 반면, 이 모듈은 의도적으로 더 일반적인 텍스트 관련 기능을 다룹니다.

  • Wansmer/treesj:

    • 트리시터(tree-sitter) 노드를 기반으로 작동합니다. 이는 일부 엣지 케이스에서 더 정확하지만 트리시터 파서가 필요합니다.

    • 주석이나 문자열 내에서 작동하지 않습니다.

비활성화

비활성화하려면 g:minisplitjoin_disable (전역) 또는 b:minisplitjoin_disable (버퍼용)을 v:true로 설정하세요. 다양한 시나리오와 사용자 정의 의도를 고려하여 모듈 기능 비활성화를 위한 정확한 규칙 작성은 사용자의 몫으로 남겨둡니다. 일반적인 레시피는 mini.nvim-disabling-recipes를 참조하세요.

용어 사전

위치 (POSITION)

각각 줄 번호와 열 번호를 포함하는 <line> 및 <col> 필드가 있는 테이블입니다. 둘 다 1부터 시작합니다. 예: { line = 2, col = 1 }.

영역 (REGION)

버퍼의 영역을 나타내는 테이블입니다. 필드: 시작 및 종료 위치(포함)를 위한 <from> 및 <to>. 예:

{ from = { line = 1, col = 1 }, to = { line = 2, col = 1 } }

setup()

MiniSplitjoin.setup({config})

모듈 설정

매개변수

{config} (table|nil) 모듈 설정 테이블. MiniSplitjoin.config를 참조하세요.

사용법

require('mini.splitjoin').setup() -- 기본 설정 사용
-- 또는
require('mini.splitjoin').setup({}) -- {}를 설정 테이블로 교체

config

MiniSplitjoin.config

기본값

MiniSplitjoin.config = {
  -- 모듈 매핑. 비활성화하려면 `''`(빈 문자열)을 사용하세요.
  -- 일반 모드와 비주얼 모드 모두에 대해 생성됩니다.
  mappings = {
    toggle = 'gS',
    split = '',
    join = '',
  },

  -- 탐지 옵션: 분할/결합을 수행할 위치
  detect = {
    -- 인자가 있는 영역을 탐지하기 위한 Lua 패턴 배열.
    -- 기본값: { '%b()', '%b[]', '%b{}' }
    brackets = nil,

    -- 인자 구분자를 정의하는 문자열 Lua 패턴
    separator = ',',

    -- 구분자에서 제외할 하위 영역에 대한 Lua 패턴 배열.
    -- 중첩된 괄호와 따옴표가 있는 경우에도 정확한 탐지를 가능하게 합니다.
    -- 기본값: { '%b()', '%b[]', '%b{}', '%b""', "%b''" }
    exclude_regions = nil,
  },

  -- 분할 옵션
  split = {
    hooks_pre = {},
    hooks_post = {},
  },

  -- 결합 옵션
  join = {
    hooks_pre = {},
    hooks_post = {},
  },
}

탐지

MiniSplitjoin.config.detect

config.detect 테이블은 Lua 패턴을 사용하여 인자를 탐지하는 방법을 제어합니다. 일반적인 아이디어는 전체 버퍼를 단일 줄로 변환하고 문자열 검색을 수행한 다음 결과를 다시 2D 위치로 변환하는 것입니다.

설정 예시:

require('mini.splitjoin').setup({
  detect = {
    -- 균형 잡힌 괄호 내부만 탐지
    brackets = { '%b()' },

    -- `,`와 `;` 모두 인자 구분자로 허용
    separator = '[,;]',

    -- 모든 구분자가 인자를 정의하도록 함
    exclude_regions = {},
  },
})
외부 괄호

detect.brackets는 감싸는 영역을 찾는 데 사용되는 Lua 패턴 배열입니다. 제공된 패턴 중 하나라도 일치하는 가장 작은 영역을 찾기 위해 전체 버퍼를 순회하여 수행됩니다.

기본값: nil, { '%b()', '%b[]', '%b{}' }로 유추됩니다. 따라서 인자는 균형 잡힌 (), [] 또는 {} 내부에 있을 수 있습니다.

예: brackets = { '%b()' }는 균형 잡힌 () 내부에서만 인자를 검색합니다.

구분자

detect.separator는 인자 구분자로 취급되어야 하는 문자열을 정의하는 단일 Lua 패턴입니다.

detect.separator의 빈 문자열은 주변 괄호만 구분자로 사용하게 됩니다.

패턴 일치의 끝부분만 분할/결합 위치로 사용됩니다.

기본값: ','. 따라서 인자는 쉼표로만 구분될 수 있습니다.

예: separator = { '[,;]' }는 ,와 ; 모두를 구분자로 취급합니다.

제외 영역

detect.exclude_regions는 구분자를 제외할 하위 영역에 대한 Lua 패턴 배열입니다. 중첩된 괄호와 따옴표의 경우에도 정확한 탐지를 가능하게 합니다.

기본값: nil; { '%b()', '%b[]', '%b{}', '%b""', "%b''" }로 유추됩니다. 따라서 구분자는 중첩된 인자 영역을 나타내는 균형 잡힌 (), [], {} 또는 문자열을 나타내는 "", '' 내부에 있을 수 없습니다.

예: exclude_regions = {}는 어떤 영역도 제외하지 않습니다. 따라서 f(a, { b, c })의 경우 두 쉼표 모두 인자 구분자로 탐지됩니다.

훅

split.hooks_pre, split.hooks_post, join.hooks_pre, join.hooks_post는 훅 함수 배열입니다. 비어 있으면(기본값) 훅이 적용되지 않습니다.

훅은 위치 배열을 인수로 받고 반환해야 합니다. MiniSplitjoin-용어 사전을 참조하세요.

동작을 미세 조정하는 데 사용할 수 있습니다:

  • 사전(pre) 훅은 동작 전에 호출됩니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 탐지된 분할/결합 위치입니다. 마지막 훅의 출력은 실제로 분할/결합을 수행하는 데 사용됩니다.

  • 사후(post) 훅은 동작 후에 호출됩니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 실제 동작에서의 분할/결합 위치와 해당 영역의 오른쪽 끝부분(마지막 위치)입니다 (훅 코드를 쉽게 작성하기 위함). 마지막 훅의 출력은 동작 반환 값으로 사용됩니다.

더 자세한 내용은 MiniSplitjoin.split() 및 MiniSplitjoin.join()을 참조하세요.

일반적인 훅을 생성하는 예제는 MiniSplitjoin.gen_hook을 참조하세요.

toggle()

MiniSplitjoin.toggle({opts})

인자 토글

개요:

  • 입력 위치에서 영역 탐지: 제공된 opts.region을 사용하거나 해당 위치를 둘러싼 가장 작은 괄호 영역을 찾습니다. 자세한 내용은 MiniSplitjoin.config.detect를 참조하세요.

  • 영역이 한 줄에 걸쳐 있으면 찾은 영역과 함께 MiniSplitjoin.split()을 사용합니다. 그렇지 않으면 MiniSplitjoin.join()을 사용합니다.

매개변수

{opts} (table|nil) 옵션. MiniSplitjoin.config의 구조를 가지며 기본값을 상속합니다.

다음과 같은 추가 선택적 필드가 허용됩니다:

  • <position> (table) - 가장 작은 괄호 영역을 찾을 위치. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: 커서 위치.

  • <region> (table) - 동작을 수행할 영역. 왼쪽 괄호에서 시작하고 오른쪽 괄호에서 끝나는 범위를 가정합니다. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: nil (영역 자동 탐지).

반환

(any) 선택된 split() 또는 join() 동작의 출력.

split()

MiniSplitjoin.split({opts})

인자 분할

개요:

  • 영역 탐지: 제공된 opts.region을 사용하거나 입력 위치(기본값은 커서 위치)를 둘러싼 가장 작은 괄호 영역을 찾습니다. 자세한 내용은 MiniSplitjoin.config.detect를 참조하세요.

  • opts의 separator 및 exclude_regions를 사용하여 구분자 위치를 찾습니다. 두 괄호 모두 구분자로 취급됩니다. 자세한 내용은 MiniSplitjoin.config.detect를 참조하세요. 참고: 구분자 위치를 찾을 수 없으면 중단합니다.

  • 구분자 위치를 분할 위치를 나타내도록 수정합니다. 마지막 분할 위치(오른쪽 괄호에서 유추됨)는 오른쪽 괄호가 새 줄로 이동할 수 있도록 왼쪽으로 한 열 이동합니다.

  • opts.split.hooks_pre의 모든 훅을 적용합니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 이전 단계에서의 분할 위치입니다. 마지막 훅의 출력은 다음 단계에서 분할 위치로 사용됩니다.

  • MiniSplitjoin.split_at()을 사용하여 분할하고 분할 위치를 업데이트합니다.

  • opts.split.hooks_post의 모든 훅을 적용합니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 이전 단계에서의 분할 위치와 해당 영역의 오른쪽 끝부분입니다 (훅 코드를 쉽게 작성하기 위함). 마지막 훅의 출력은 함수 반환 값으로 사용됩니다.

참고:

  • 설계상 인자가 분할되어야 하는지 여부를 감지하지 않으므로, 여러 줄에 걸쳐 있는 인자에 적용하면 원치 않는 결과가 발생할 수 있습니다.

매개변수

{opts} (table|nil) 옵션. MiniSplitjoin.config의 구조를 가지며 기본값을 상속합니다.

다음과 같은 추가 선택적 필드가 허용됩니다:

  • <position> (table) - 가장 작은 괄호 영역을 찾을 위치. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: 커서 위치.

  • <region> (table) - 동작을 수행할 영역. 왼쪽 괄호에서 시작하고 오른쪽 괄호에서 끝나는 범위를 가정합니다. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: nil (영역 자동 탐지).

반환

(any) 마지막 opts.split.hooks_post의 출력 또는 분할 위치를 찾을 수 없는 경우 nil. 기본값: MiniSplitjoin.split_at() 적용의 반환 값.

join()

MiniSplitjoin.join({opts})

인자 결합

개요:

  • 영역 탐지: 제공된 opts.region을 사용하거나 입력 위치(기본값은 커서 위치)를 둘러싼 가장 작은 괄호 영역을 찾습니다. 자세한 내용은 MiniSplitjoin.config.detect를 참조하세요.

  • 마지막 영역 줄을 제외한 모든 영역 줄의 끝부분을 결합 위치로 계산합니다. 참고: 결합 위치를 찾을 수 없으면 중단합니다.

  • opts.join.hooks_pre의 모든 훅을 적용합니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 이전 단계에서의 결합 위치입니다. 마지막 훅의 출력은 다음 단계에서 결합 위치로 사용됩니다.

  • MiniSplitjoin.join_at()을 사용하여 결합하고 결합 위치를 업데이트합니다.

  • opts.join.hooks_post의 모든 훅을 적용합니다. 각각 이전 훅의 출력에 적용됩니다. 첫 번째 훅의 입력은 이전 단계에서의 결합 위치와 영역의 오른쪽 끝부분입니다 (훅 코드를 쉽게 작성하기 위함). 마지막 훅의 출력은 함수 반환 값으로 사용됩니다.

매개변수

{opts} (table|nil) 옵션. MiniSplitjoin.config의 구조를 가지며 기본값을 상속합니다.

다음과 같은 추가 선택적 필드가 허용됩니다:

  • <position> (table) - 가장 작은 괄호 영역을 찾을 위치. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: 커서 위치.

  • <region> (table) - 동작을 수행할 영역. 왼쪽 괄호에서 시작하고 오른쪽 괄호에서 끝나는 범위를 가정합니다. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 기본값: nil (영역 자동 탐지).

반환

(any) 마지막 opts.split.hooks_post의 출력 또는 결합 위치를 찾을 수 없는 경우 nil. 기본값: MiniSplitjoin.join_at() 적용의 반환 값.

gen_hook

MiniSplitjoin.gen_hook

일반적인 훅 생성

함수 요소를 가진 테이블입니다. 훅을 실제로 가져오려면 호출하세요.

생성된 모든 사후(post) 훅은 훅 내부에서 수행된 변경 사항을 반영하여 업데이트된 입력 버전을 반환합니다.

lua 파일 타입의 예시 (이를 ‘lua.lua’ 파일 타입 플러그인인 ftplugin에 배치):

local gen_hook = MiniSplitjoin.gen_hook
local curly = { brackets = { '%b{}' } }

-- 중괄호 내부에서 분할할 때 후행 쉼표 추가
local add_comma_curly = gen_hook.add_trailing_separator(curly)

-- 중괄호 내부에서 결합할 때 후행 쉼표 삭제
local del_comma_curly = gen_hook.del_trailing_separator(curly)

-- 결합 후 중괄호를 단일 공백으로 패딩
local pad_curly = gen_hook.pad_brackets(curly)

-- 버퍼 로컬 설정 생성
vim.b.minisplitjoin_config = {
  split = { hooks_post = { add_comma_curly } },
  join  = { hooks_post = { del_comma_curly, pad_curly } },
}

gen_hook.pad_brackets()

MiniSplitjoin.gen_hook.pad_brackets({opts})

괄호를 패딩하는 훅 생성

이것은 결합 사후(post) 훅입니다. MiniSplitjoin.config의 join.hooks_post에서 사용하세요.

매개변수

{opts} (table|nil) 옵션. 가능한 필드:

  • <pad> (string) - 첫 번째 및 마지막 결합 위치 전후에 추가할 패딩. 기본값: ' ' (단일 공백).

  • <brackets> (table) - 동작을 수행할 괄호 패턴 배열. MiniSplitjoin.config.detect의 brackets와 구조가 동일합니다. 기본값: MiniSplitjoin.config.detect.brackets.

반환

(function) 첫 번째와 마지막 결합 위치에 내부 패딩을 추가하고 업데이트된 입력 결합 위치를 반환하는 훅입니다.

gen_hook.add_trailing_separator()

MiniSplitjoin.gen_hook.add_trailing_separator({opts})

후행 구분자를 추가하는 훅 생성

이것은 분할 사후(post) 훅입니다. MiniSplitjoin.config의 split.hooks_post에서 사용하세요.

매개변수

{opts} (table|nil) 옵션. 가능한 필드:

  • <sep> (string) - 마지막 분할 위치 앞에 추가할 구분자. 기본값: ','.

  • <brackets> (table) - 동작을 수행할 괄호 패턴 배열. MiniSplitjoin.config.detect의 brackets와 구조가 동일합니다. 기본값: MiniSplitjoin.config.detect.brackets.

반환

(function) 마지막 분할 위치 앞에 구분자를 추가하고 업데이트된 입력 분할 위치를 반환하는 훅입니다.

gen_hook.del_trailing_separator()

MiniSplitjoin.gen_hook.del_trailing_separator({opts})

후행 구분자를 삭제하는 훅 생성

매개변수

{opts} (table|nil) 옵션. 가능한 필드:

  • <sep> (string) - 마지막 결합 위치 앞에서 제거할 구분자. 기본값: ','.

  • <brackets> (table) - 동작을 수행할 괄호 패턴 배열. MiniSplitjoin.config.detect의 brackets와 구조가 동일합니다. 기본값: MiniSplitjoin.config.detect.brackets.

반환

(function) 마지막 분할 위치 앞에 구분자를 추가하고 업데이트된 입력 분할 위치를 반환하는 훅입니다.

split_at()

MiniSplitjoin.split_at({positions})

특정 위치에서 분할

개요:

  • 각 위치에 대해 그 뒤의 모든 문자를 다음 줄로 이동시키고 현재 줄과 동일한 들여쓰기를 갖도록 합니다 (MiniSplitjoin.get_indent_part() 참조). 또한 해당 위치 줄의 후행 공백을 제거합니다.

  • 내부 줄의 들여쓰기를 단일 패딩만큼 늘립니다: ‘noexpandtab’의 경우 탭, 그렇지 않으면 shiftwidth() 수만큼의 공백.

참고:

  • 커서는 텍스트 업데이트를 따르도록 조정됩니다.

  • 입력 위치를 추적하려면 이 함수의 출력을 사용하세요.

매개변수

{positions} (table) 분할을 수행할 위치 배열. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 참고: 정렬될 필요는 없지만, 들여쓰기가 증가할 줄을 유추하기 위해 첫 번째와 마지막 위치가 사용됩니다.

반환

(table) 입력 positions가 이동된 새 위치 배열.

join_at()

MiniSplitjoin.join_at({positions})

특정 위치에서 결합

개요:

  • 각 위치에 대해 해당 줄과 다음 줄을 결합합니다. 결합은 줄의 후행 공백과 다음 줄의 들여쓰기(MiniSplitjoin.get_indent_part() 참조)를 패딩 문자열(첫 번째와 마지막 위치의 빈 문자열을 제외하고 단일 공백)로 교체하여 수행됩니다. 이를 조정하려면 훅을 사용하세요 (예를 들어 MiniSplitjoin.gen_hook.pad_brackets() 참조).

참고:

  • 커서는 텍스트 업데이트를 따르도록 조정됩니다.

  • 입력 위치를 추적하려면 이 함수의 출력을 사용하세요.

매개변수

{positions} (table) 결합을 수행할 위치 배열. 구조는 MiniSplitjoin-용어 사전을 참조하세요. 참고: 정렬될 필요는 없지만, 첫 번째와 마지막 위치는 서로 다른 패딩 문자열을 가집니다.

반환

(table) 입력 positions가 이동된 새 위치 배열.

MiniSplitjoin.get_visual_region()

참고:

  • 두 마크 모두 영역에 포함됩니다.

  • 줄 단위(linewise) 모드에서 시작 위치는 1열이고 끝 위치는 해당 줄의 마지막 문자입니다.
