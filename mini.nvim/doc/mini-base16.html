mini.base16 Base16 색상 구성표 생성

MIT 라이선스 Copyright (c) 2021 Evgeni Chasnovski

모듈

현대적인 Neovim Lua 플러그인에 맞게 조정된 chriskempson/base16 색상 구성표(Copyright (C) 2012 Chris Kempson)의 빠른 구현입니다. 추가 기능:

  • 구성 가능한 cterm 색상 자동 지원 (highlight-cterm 참고).

  • 배경 및 전경 색상만을 기반으로 한 독자적인 팔레트 생성기.

설정

이 모듈은 require('mini.base16').setup({})으로 설정이 필요합니다 ({}를 config 테이블로 교체하세요). 스크립팅이나 수동으로 (:lua MiniBase16.*) 사용할 수 있는 전역 Lua 테이블 MiniBase16이 생성됩니다.

config 구조와 기본값은 MiniBase16.config를 참고하세요.

이 모듈은 런타임 옵션이 없으므로 vim.b.minibase16_config를 사용해도 효과가 없습니다.

예시:

require('mini.base16').setup({
  palette = {
    base00 = '#112641',
    base01 = '#3a475e',
    base02 = '#606b81',
    base03 = '#8691a7',
    base04 = '#d5dc81',
    base05 = '#e2e98f',
    base06 = '#eff69c',
    base07 = '#fcffaa',
    base08 = '#ffcfa0',
    base09 = '#cc7e46',
    base0A = '#46a436',
    base0B = '#9ff895',
    base0C = '#ca6ecf',
    base0D = '#42f7ff',
    base0E = '#ffc4ff',
    base0F = '#00a5c5',
  },
  use_cterm = true,
  plugins = {
    default = false,
    ['nvim-mini/mini.nvim'] = true,
  },
})

참고

  1. 이것은 플러그인의 일부 색상 구성표를 생성하는 데 사용됩니다 (MiniBase16-color-schemes 참고).

  2. setup()을 사용한다고 해서 실제로 :colorscheme이 생성되지는 않습니다. 기본적으로 조율된 highlight-groups 세트를 생성합니다. 자신만의 테마를 만들려면:

    • “runtimepath”에서 접근 가능한 “colors” 디렉토리(보통 Neovim 설정 디렉토리 내부의 “colors”면 충분함) 안에 “myscheme.lua”(선택한 테마 이름으로 명명) 파일을 넣으세요.

    • “myscheme.lua” 내부에서 팔레트와 함께 require('mini.base16').setup()을 호출한 다음 g:colors_name을 “myscheme”으로 설정하세요.

색상 구성표

Base16 색상 구성표

이 모듈에는 몇 가지 사전 빌드된 색상 구성표가 포함되어 있습니다. 각각은 다음 Lua 코드의 더 빠른 버전으로 생성된 mini.base16 테마입니다:

require('mini.base16').setup({ palette = palette, use_cterm = true })

일반적인 :colorscheme으로 활성화하세요 (예: :colorscheme minischeme).

minischeme

높은 대비와 채도 팔레트를 가진 파란색과 노란색 주 색상입니다. 팔레트는 다음과 같습니다:

-- 어두운 'background'용:
MiniBase16.mini_palette('#112641', '#e2e98f', 75)

-- 밝은 'background'용:
MiniBase16.mini_palette('#e2e5ca', '#002a83', 75)

중간 정도의 대비와 채도 팔레트를 가진 청록색과 회색 주 색상입니다. 팔레트는 다음과 같습니다:

-- 어두운 'background'용:
MiniBase16.mini_palette('#0A2A2A', '#D0D0D0', 50)

-- 밝은 'background'용:
MiniBase16.mini_palette('#C0D2D2', '#262626', 80)

setup()

MiniBase16.setup({config})

모듈 설정

설정은 색상 구성표를 활성화하기 위해 base16 팔레트를 적용하여 수행됩니다. 하이라이트 그룹은 원래 base16-vim 플러그인의 확장 세트입니다. config.palette가 원래 스타일링 원칙을 준수하도록 하는 것이 좋습니다.

기본적으로 ‘gui 하이라이팅’ (highlight-gui 및 ‘termguicolors’ 참고)만 지원됩니다. ‘cterm 하이라이팅’ (highlight-cterm 참고)을 지원하려면 다음 형식 중 하나로 config.use_cterm 인수를 제공하세요:

  • true로 설정하면 palette에서 자동으로 생성 (가장 가까운 색상으로).

  • palette와 유사한 구조를 갖지만 hex 문자열 대신 터미널 색상(0에서 255 사이의 정수)을 갖는 테이블.

매개변수

{config} (table) 모듈 설정 테이블. MiniBase16.config를 참고하세요.

사용법

require('mini.base16').setup({}) -- {}를 설정 테이블로 교체하세요
                                 -- `palette` 필드가 있어야 합니다

config

MiniBase16.config

기본값

MiniBase16.config = {
  -- base00에서 base0F까지의 이름과 "#RRGGBB" 형식의 HEX 색상 문자열 값을
  -- 갖는 테이블입니다. 참고: 이것은 setup()에서 명시적으로 제공되어야 합니다.
  palette = nil,

  -- cterm 색상을 지원할지 여부입니다. 불리언, `nil` (false와 동일)
  -- 또는 cterm 색상이 포함된 테이블일 수 있습니다. 자세한 내용은
  -- setup() 문서를 참고하세요.
  use_cterm = nil,

  -- 플러그인 통합입니다. 모든 통합을 비활성화하려면 `default = false`를
  -- 사용하세요. 플러그인별로 설정할 수도 있습니다 (|MiniBase16.config| 참고).
  plugins = { default = true },
}

플러그인 통합

config.plugins는 지원되는 어떤 플러그인에 대해 하이라이트 그룹을 생성할지 정의합니다. 통합 수를 제한하면 시작 시간이 약간 단축됩니다. 다음과 같이 적용되는 불리언 (true/false) 값을 갖는 테이블입니다:

  • 플러그인 이름(mini.base16에 나열된 대로)에 항목이 있으면 해당 항목이 사용됩니다.

  • 그렇지 않으면 config.plugins.default가 사용됩니다.

“mini.nvim” 통합만 로드하는 예시:

require('mini.base16').setup({
  palette = require('mini.base16').mini_palette('#112641', '#e2e98f', 75),
  plugins = {
    default = false,
    ['nvim-mini/mini.nvim'] = true,
  }
})

mini_palette()

MiniBase16.mini_palette({background}, {foreground}, {accent_chroma})

‘mini’ 팔레트 생성

기본 배경 및 전경의 HEX (문자열 ‘#RRGGBB’) 색상을 기반으로 base16 팔레트를 생성하며, 선택적으로 강조 채도(상세 내용 참고)를 설정할 수 있습니다.

알고리즘 설계

  • 주요 작동 색 공간은 지각적으로 균일한 CIELUV 색 공간의 원통형 표현인 CIELCh(uv)입니다. 밝기 L(0에서 100까지의 값), 채도(양수 값), 색조(0에서 360도까지의 원형 값)의 세 가지 값으로 색상을 정의합니다. 유용한 변환 도구: https://www.easyrgb.com/en/convert.php

  • 네 가지 중요한 밝기 값이 있습니다: 배경, 전경, 초점(배경과 전경의 중간 정도이며 전경에 가깝음), 가장자리(전경에 가장 가까운 극한의 밝기).

  • 처음 네 가지 색상은 background와 동일한 채도 및 색조를 갖지만 밝기는 배경에서 초점으로 진행됩니다.

  • 다음 네 가지 색상은 foreground와 동일한 채도 및 색조를 갖지만 밝기는 ‘base05’ 색상이 주요 전경색이 되도록 전경에서 가장자리로 진행됩니다.

  • 나머지 8가지 색상은 쌍으로 생성되는 강조 색상입니다.

    • 각 쌍은 배경 및 전경 색조(각 채도가 양수인 경우)와 ‘가장 다른’ 색조 세트에서 동일한 색조를 갖습니다.

    • 모든 색상은 accent_chroma와 동일한 채도를 갖습니다 (제공되지 않으면 전경의 채도가 사용됩니다. 서로 옆에 나타나기 때문입니다). 참고: 이는 전경 채도가 낮은 경우 accent_chroma를 수동으로 설정하는 것이 좋음을 의미합니다. 30(낮은 채도)에서 80(높은 채도) 사이의 값이 일반적입니다.

    • 쌍 내부에는 기본 밝기(전경 밝기와 동일)와 대체 밝기(초점 밝기와 동일)가 있습니다. 기본 밝기는 코드에서 더 자주 사용되는 색상으로 이동합니다: base08 (변수), base0B (문자열), base0D (함수), base0E (키워드). 강조 색상이 base16 팔레트에 정확히 어떻게 매핑되는지는 시행착오의 결과입니다. 한 가지 경험 법칙은 다음과 같습니다: 한 색조 쌍 내의 색상은 서로 옆에서 더 자주 보여야 합니다. 이는 색상을 구별하기 더 쉽고 시각적으로 더 매력적으로 보이기 때문입니다. 그렇기 때문에 base0D와 base0F는 보통 함수와 구분 기호(괄호 포함)를 나타내므로 동일한 색조를 갖습니다.

매개변수

{background} (string) 배경 HEX 색상 (#RRGGBB 형식).

{foreground} (string) 전경 HEX 색상 (#RRGGBB 형식).

{accent_chroma} (number) 선택적인 양수 (보통 0에서 100 사이). 기본값: 전경색의 채도.

반환값

(table) base16 팔레트가 포함된 테이블.

사용법

local p = require('mini.base16').mini_palette('#112641', '#e2e98f', 75)
require('mini.base16').setup({ palette = p })

rgb_palette_to_cterm_palette()

MiniBase16.rgb_palette_to_cterm_palette({palette})

RGB 색상의 팔레트를 터미널 색상으로 변환

속도를 높이기 위해 use_cterm 변수를 캐싱하는 데 유용합니다.

매개변수

{palette} (table) base16 팔레트 테이블 (MiniBase16.config.palette와 동일).

반환값

(table) highlight-cterm을 사용하는 base16 팔레트 테이블.
