mini.align 문서

’mini.nvim’의 main 브랜치에서 생성됨

mini.align 대화형으로 텍스트 정렬

MIT License Copyright (c) 2022 Evgeni Chasnovski

모듈

정렬 규칙과 사용자 상호작용 모두에 대해 풍부하고 유연한 사용자 정의를 제공합니다. Normal 모드(텍스트 개체/동작 시; 점 반복 포함)와 Visual 모드 모두에서 문자 단위(charwise), 줄 단위(linewise), 블록 단위(blockwise) 선택과 함께 작동합니다.

기능:

  • 정렬은 세 가지 주요 단계로 수행됩니다:

    • <Split> Lua 패턴 또는 사용자가 제공한 규칙에 따라 줄을 여러 부분으로 나눕니다.

    • <Justify> 열 내부에서 특정 측면이 동일한 너비가 되도록 각 부분을 조정합니다.

    • <Merge> 사용자 정의 가능한 구분 기호를 사용하여 각 부분을 다시 줄로 병합합니다.

    각 주요 단계 앞에는 고도로 사용자 정의된 결과를 얻기 위해 다른 단계(사전 단계)가 올 수 있습니다. MiniAlign.config의 steps 값을 참조하세요. 자세한 내용은 MiniAlign-용어집 및 MiniAlign-알고리즘을 참조하세요.

  • 사용자는 사용자 정의 가능한 수식어(정렬 단계 및/또는 옵션이 어떻게 변경되어야 하는지를 나타내는 단일 키)를 눌러 대화형으로 정렬을 제어할 수 있습니다. 일부 기본 수식어는 다음과 같습니다:

    • Lua 패턴 분할을 입력하려면 s를 누릅니다.

    • 사용 가능한 정렬 측면(“left”, “center”, “right”, “none”) 중에서 선택하려면 j를 누릅니다.

    • 병합 구분 기호를 입력하려면 m을 누릅니다.

    • 어떤 부분이 영향을 받을지 구성하기 위해 필터 Lua 표현식을 입력하려면 f를 누릅니다(예: “첫 번째 열만 정렬”).

    • 일반적으로 원치 않는 일부 분할 일치를 무시하려면 i를 누릅니다.

    • 이웃한 부분들을 쌍으로 묶어 함께 정렬하려면 p를 누릅니다.

    • 각 부분에서 공백을 제거하려면 t를 누릅니다.

    • 마지막 사전 단계를 삭제하려면 <BS>(백스페이스)를 누릅니다.

    자세한 내용은 MiniAlign-내장-수식어 및 MiniAlign-예제를 참조하세요.

  • 정렬은 즉시 미리보기(각 수식어 입력 후 결과가 업데이트됨)와 함께 수행되거나 미리보기 없이(기본값이 아닌 분할 패턴이 설정된 후 결과가 표시되고 수락됨) 수행될 수 있습니다.

  • 모든 사용자 상호작용에는 현재 정렬 프로세스에 대한 관련 정보를 보여주는 도우미 상태 메시지가 동반됩니다.

설정

이 모듈은 require('mini.align').setup({})으로 설정이 필요합니다({}를 config 테이블로 교체하세요). 이는 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniAlign을 생성합니다(:lua MiniAlign.* 사용).

사용 가능한 설정에 대해서는 MiniAlign.config를 참조하세요.

vim.b.minialign_config를 통해 버퍼 로컬에서 런타임 설정(예: config.modifiers)을 재정의할 수 있으며, 이는 MiniAlign.config와 동일한 구조를 가져야 합니다. 자세한 내용은 mini.nvim-버퍼-로컬-설정을 참조하세요.

모듈이 오류가 아닌 피드백을 표시하지 않도록 하려면 config.silent = true로 설정하세요.

비교

  • junegunn/vim-easy-align:

    • ’mini.align’은 주로 ’junegunn/vim-easy-align’을 본따 설계되었으므로 많은 유사점이 있습니다.

    • 두 플러그인 모두 사용자가 수식어 키를 눌러 대화형으로 정렬 옵션을 변경할 수 있도록 허용합니다(비록 기본값은 완전히 다르지만). ’junegunn/vim-easy-align’은 이러한 수식어가 고정되어 있는 반면, ’mini.align’은 완전한 사용자 정의를 허용합니다. 예제는 MiniAlign.config를 참조하세요.

    • ’junegunn/vim-easy-align’은 구분 기호를 문자열의 다른 부분과 다르게 처리하도록 설계되었습니다. ’mini.align’은 설계상 분할된 부분들을 서로 구별하지 않습니다. 구분 기호로 분할하는 것 외에 다른 논리에 기반한 분할이 허용됩니다.

    • ’junegunn/vim-easy-align’은 처음에 첫 번째 구분 기호로만 정렬합니다. ’mini.align’은 처음에 모든 구분 기호로 정렬합니다.

    • ‘junegunn/vim-easy-align’은 구분 기호 행 번호별 특수 필터링을 구현합니다. ’mini.align’은 수식어 단계에서 사용자가 제공한 Lua 코드를 기반으로 한 내장 필터링 기능을 제공합니다. MiniAlign.gen_step.filter() 및 ’f’ 내장 수식어를 참조하세요.

    • ’mini.align’은 등록되지 않은 모든 수식어를 일반 구분 기호 패턴으로 처리하지만, ’junegunn/vim-easy-align’은 그렇지 않습니다.

    • ’mini.align’은 문자열 정렬에 사용되는 핵심 Lua 함수(MiniAlign.align_strings())를 내보냅니다.

  • godlygeek/tabular:

    • ’godlygeek/tabular’은 주로 매개변수를 입력하여 사용자 정의되는 단일 명령을 중심으로 설계되었습니다. ’mini.align’은 사용자 정의 가능한 단일 문자 수식어를 누르는 대화형 정렬이라는 다른 개념을 구현합니다.

    • ’godlygeek/tabular’은 정렬이 바람직할 수 있는 영역을 감지할 수 있습니다. ’mini.align’은 설계상 그렇지 않습니다. 정렬할 영역을 명시적으로 정의하려면 Visual 선택이나 텍스트 개체/동작을 사용하세요.

비활성화

비활성화하려면 vim.g.minialign_disable(전역) 또는 vim.b.minialign_disable(버퍼용)을 true로 설정하세요. 다양한 시나리오와 사용자 정의 의도를 고려할 때, 모듈 기능을 비활성화하기 위한 정확한 규칙을 작성하는 것은 사용자의 몫으로 남겨둡니다. 일반적인 방법은 mini.nvim-비활성화-레시피를 참조하세요.

용어집

부분 (PARTS)

문자열의 2차원 배열(문자열 배열의 배열)입니다. MiniAlign.as_parts()에서 자세히 알아보세요.

행 (ROW)

부분들의 첫 번째 레벨 배열입니다(예: parts[1]).

열 (COLUMN)

동일한 두 번째 레벨 인덱스를 가진 부분 요소들로 구성된 문자열 배열입니다(예: { parts[1][1], parts[2][1], ... }).

단계 (STEP)

이름이 지정된 호출 가능한 객체(callable)입니다. MiniAlign.new_step()을 참조하세요. 정렬 단계 측면에서 사용될 때, 이 호출 가능한 객체는 두 개의 인수를 받습니다: 객체(부분 또는 문자열 배열)와 옵션 테이블.

분할 (SPLIT)

문자열 배열을 가져와서 부분(parts)으로 변환하는 프로세스입니다.

조정 (JUSTIFY)

부분들을 가져와 정렬된 부분(열 내부의 모든 요소가 동일한 너비를 가짐)으로 변환하는 프로세스입니다.

병합 (MERGE)

부분들을 가져와 다시 문자열 배열로 변환하는 프로세스입니다. 보통 행들을 문자열로 연결하여 수행합니다.

영역 (REGION)

버퍼의 영역을 나타내는 테이블입니다. <from> / <to> 필드는 포함적인 시작 / 끝 위치를 가집니다(<to>는 빈 영역을 설명하기 위해 nil일 수 있습니다). 위치 또한 <line> 및 <col> 필드를 가진 테이블입니다(둘 다 1부터 시작).

모드 (MODE)

문자 단위(“char”, v), 줄 단위(“line”, V) 또는 블록 단위(“block”, <C-v>) 중 하나입니다.

알고리즘

’mini.align’에는 문자열 정렬과 대화형 영역 정렬이라는 두 가지 주요 프로세스가 구현되어 있습니다. 사용된 용어에 대한 자세한 정보는 MiniAlign-용어집을 참조하세요.

문자열 정렬

주요 구현은 MiniAlign.align_strings()에 있습니다. 입력은 문자열 배열이고 출력은 정렬된 문자열 배열입니다. 프로세스는 세 가지 주요 단계(분할, 조정, 병합)로 구성되며, 각 단계 앞에는 임의의 수의 사전 단계(사전 분할, 사전 조정, 사전 병합)가 올 수 있습니다.

알고리즘:

  • <Pre-split>. 입력 문자열 배열을 가져와 모든 사전 분할 단계(steps.pre_split)를 연속적으로 적용합니다. 각 단계는 (strings, opts) 시그니처를 가지며 배열을 직접 수정해야 합니다.

  • <Split>. 문자열 배열을 가져와 steps.split()을 사용하여 부분(parts)으로 변환합니다. (strings, opts) 시그니처를 가지며 부분들을 반환해야 합니다.

  • <Pre-justify>. 부분들을 가져와 모든 사전 조정 단계(steps.pre_justify)를 연속적으로 적용합니다. 각 단계는 (parts, opts) 시그니처를 가지며 부분들을 직접 수정해야 합니다.

  • <Justify>. 부분들을 가져와 steps.justify()를 적용합니다. (parts, opts) 시그니처를 가지며 부분들을 직접 수정해야 합니다.

  • <Pre-merge>. 부분들을 가져와 모든 사전 병합 단계(steps.pre_merge)를 연속적으로 적용합니다. 각 단계는 (parts, opts) 시그니처를 가지며 부분들을 직접 수정해야 합니다.

  • <Merge>. 부분들을 가져와 steps.merge()를 사용하여 문자열 배열로 변환합니다. (parts, opts) 시그니처를 가지며 문자열 배열을 반환해야 합니다.

참고:

  • 모든 테이블 객체는 처음에 복사되므로, 직접 수정이 워크플로우에 영향을 주지 않습니다.

  • 기본 주요 단계는 옵션을 통해 제어되도록 설계되었습니다. MiniAlign.align_strings() 및 MiniAlign.gen_step의 기본 단계 항목을 참조하세요.

  • 모든 단계는 두 번째 인수로 동일한 옵션 테이블을 받도록 보장됩니다. 이를 통해 단계들이 서로 “대화”할 수 있습니다. 즉, 이전 단계가 이후 단계로 데이터를 전달할 수 있습니다.

대화형 영역 정렬

대화형 정렬은 대부분의 사용자에게 주요 진입점입니다. 두 가지 방식으로 수행될 수 있습니다:

  • <Without-preview> (미리보기 없음). MiniAlign.config.mappings의 start에 정의된 매핑을 통해 시작됩니다. 분할 패턴이 기본값이 아닌 것으로 설정되면 정렬이 수락됩니다.

  • <With-preview> (미리보기 포함). MiniAlign.config.mappings의 start_with_preview에 정의된 매핑을 통해 시작됩니다. 정렬 결과는 모든 수식어 입력 후 표시되며 <CR>(Enter)을 누르면 수락됩니다. 참고: 각 미리보기는 현재 정렬 단계와 옵션을 미리보기에 표시되는 현재 줄이 아닌, 초기 영역 줄에 적용하여 수행됩니다.

수명 주기 (기본 매핑 가정):

  • <Initiate-alignment>:

    • Normal 모드에서 ga(또는 미리보기를 보려면 gA)를 입력한 후 정렬할 영역을 정의하는 텍스트 개체 또는 동작을 입력합니다.

    • Visual 모드에서 영역을 선택하고 ga(또는 미리보기를 보려면 gA)를 입력합니다. 선택한 영역에 포함된 문자열이 MiniAlign.align_strings()의 입력으로 사용됩니다. 영역을 선택할 때 모드에 유의하세요: 문자 단위(v), 줄 단위(V), 블록 단위(<C-v>). 모두 다르게 작동합니다.

  • <Press-modifiers>. 단일 키를 하나씩 누릅니다:

    • 누른 키가 MiniAlign.config의 modifiers 테이블 키 중 하나인 경우, 해당 함수 값이 실행됩니다. 보통 일부 옵션을 수정하거나 일부 사전 단계에 영향을 미칩니다.

    • 누른 키가 정의된 수식어 중 하나가 아닌 경우, 일반 분할 패턴으로 처리됩니다. 이 프로세스는 저절로 종료되거나(대개 미리보기가 없고 기본값이 아닌 분할 패턴이 설정된 경우) 수동으로 종료할 수 있습니다.

  • <Accept-or-discard>. 미리보기가 활성화된 경우, <CR>을 눌러 현재 결과를 수락합니다. 결과를 폐기하고 초기 영역으로 돌아가려면 <Esc> 또는 <C-c>를 누르세요.

자세한 내용은 MiniAlign-내장-수식어 및 MiniAlign-예제를 참조하세요.

참고:

  • Visual 블록 단위 선택은 ’virtualedit’이 “block” 또는 “all”로 설정되어 있을 때 가장 잘 작동합니다.

  • 미리보기가 포함된 정렬은 ’showmode’가 비활성화되어 있을 때 가장 잘 작동합니다.

내장 수식어

내장 수식어 개요

모든 예제는 줄 단위 모드에서 미리보기를 포함한 대화형 정렬을 가정합니다. 기본 매핑을 사용하면 V로 줄을 선택하고 gA로 정렬을 시작합니다. 줄을 수정 가능한 버퍼에 복사하여 직접 실험해보는 것이 도움이 될 수 있습니다.

참고:

  • 정의된 수식어가 없는 누른 키는 일반 분할 패턴으로 처리됩니다.

  • 모든 수식어는 MiniAlign.setup() 내에서 사용자 정의할 수 있습니다. MiniAlign.config의 “수식어” 섹션을 참조하세요.

주요 옵션 수식어

<s> 분할 패턴을 입력합니다(<CR>을 눌러 확인). 입력은 일반 구분 기호로 처리됩니다.

전:

a-b-c
aa-bb-cc

s-<CR> 입력 후:

a -b -c
aa-bb-cc

<j> 조정 측면을 선택합니다. 사용자에게 측면의 단일 문자 식별자를 입력하도록 요청합니다(도우미 메시지와 함께): left(왼쪽), center(가운데), right(오른쪽), none(없음).

전:

a_b_c
aa_bb_cc

_jr 입력 후(먼저 _로 분할):

 a_ b_ c
aa_bb_cc

<m> 병합 구분 기호를 입력합니다(<CR>을 눌러 확인).

전:

a_b_c
aa_bb_cc

_m--<CR> 입력 후(먼저 _로 분할):

a --_--b --_--c
aa--_--bb--_--cc

사전 단계를 추가하는 수식어

<f> 필터 표현식을 입력합니다. 자세한 내용은 MiniAlign.gen_step.filter()를 참조하세요.

전:

a_b_c
aa_bb_cc

_fn==1<CR> 입력 후(먼저 _로 분할):

a _b_c
aa_bb_cc

<i> 일부 분할 일치를 무시합니다. 일반적으로 사용되는 패턴을 추가하여 split_exclude_patterns 옵션을 수정합니다. 자세한 내용은 MiniAlign.gen_step.ignore_split()를 참조하세요.

전:

/* This_is_assumed_to_be_comment */
a"_"_b
aa_bb

_i 입력 후(먼저 _로 분할):

/* This_is_assumed_to_be_comment */
a"_"_b
aa  _bb

<p> 인접한 부분들을 쌍으로 묶습니다.

전:

a_b_c
aaa_bbb_ccc

_p 입력 후(먼저 _로 분할):

a_  b_  c
aaa_bbb_ccc

<t> 양쪽의 공백을 제거합니다(들여쓰기 유지).

전:

a   _   b   _   c
  aa _bb _cc

_t 입력 후(먼저 _로 분할):

a   _b _c
  aa_bb_cc

마지막 사전 단계 삭제

<BS> 사전 단계 중 하나를 삭제합니다. 사전 단계의 종류가 하나뿐인 경우 마지막으로 추가된 단계를 삭제합니다. 그렇지 않은 경우 사용자에게 단일 문자를 입력하여 삭제할 사전 단계 종류를 선택하도록 요청합니다: split(분할), justify(조정), merge(병합).

예제:

  • tp<BS>는 “trim” 단계만 남깁니다.

  • it<BS>는 삭제할 단계를 선택하도록 요청합니다(이 경우 사전 분할 또는 사전 조정).

일반적인 분할을 위한 특수 구성

<=> 연속된 “=” 그룹으로 정렬하기 위해 특수 패턴을 사용합니다. 앞에는 임의의 수의 문장 부호가 올 수 있고 뒤에는 몇몇 일반적인 문장 부호가 올 수 있습니다. 공백을 제거하고 단일 공백으로 병합합니다.

전:

a=b
aa<=bb
aaa===bbb
aaaa   =   cccc

= 입력 후:

a    =   b
aa   <=  bb
aaa  === bbb
aaaa =   cccc

<,> “,” 문자로 분할하는 것 외에, 공백을 제거하고 인접한 부분을 쌍으로 묶으며 단일 공백으로 병합합니다.

전:

a,b
aa,bb
aaa    ,    bbb

, 입력 후:

a,   b
aa,  bb
aaa, bbb

<|> “|” 문자로 분할하고, 공백을 제거하며 단일 공백으로 병합합니다.

전:

|a|b|
|aa|bb|
|aaa    |    bbb   |

| 입력 후:

| a   | b   |
| aa  | bb  |
| aaa | bbb |

<Space> (스페이스바) 연속된 공백을 단일 공백으로 압축하고(가능한 들여쓰기 제외) %s+ 패턴으로 분할합니다(들여쓰기 유지).

전:

a b c
  aa    bb   cc

<Space> 입력 후:

```
a  b  c
aa bb cc
```

setup()

MiniAlign.setup({config})

모듈 설정

매개변수

{config} (table|nil) 모듈 설정 테이블. MiniAlign.config를 참조하세요.

사용법

require('mini.align').setup() -- 기본 설정 사용
-- 또는
require('mini.align').setup({}) -- {}를 설정 테이블로 교체

config

MiniAlign.config

기본값

MiniAlign.config = {
  -- 모듈 매핑. 비활성화하려면 `''`(빈 문자열)을 사용하세요.
  mappings = {
    start = 'ga',
    start_with_preview = 'gA',
  },

  -- 정렬 단계 및/또는 옵션을 변경하는 수식어
  modifiers = {
    -- 주요 옵션 수식어
    ['s'] = --<function: 분할 패턴 입력>,
    ['j'] = --<function: 조정 측면 선택>,
    ['m'] = --<function: 병합 구분 기호 입력>,

    -- 사전 단계를 추가하는 수식어
    ['f'] = --<function: Lua 표현식을 입력하여 부분 필터링>,
    ['i'] = --<function: 일부 분할 일치 무시>,
    ['p'] = --<function: 부분 쌍 묶기>,
    ['t'] = --<function: 공백 제거>,

    -- 마지막 사전 단계 삭제
    ['<BS>'] = --<function: 마지막 사전 단계 삭제>,

    -- 일반적인 분할을 위한 특수 구성
    ['='] = --<function: '='을 위한 강화된 설정>,
    [','] = --<function: ','를 위한 강화된 설정>,
    ['|'] = --<function: '|'를 위한 강화된 설정>,
    [' '] = --<function: ' '를 위한 강화된 설정>,
  },

  -- 정렬 프로세스를 제어하는 기본 옵션
  options = {
    split_pattern = '',
    justify_side = 'left',
    merge_delimiter = '',
  },

  -- 정렬을 수행하는 기본 단계 (`nil`인 경우 기본값 사용)
  steps = {
    pre_split = {},
    split = nil,
    pre_justify = {},
    justify = nil,
    pre_merge = {},
    merge = nil,
  },

  -- 오류가 아닌 피드백 표시를 비활성화할지 여부
  -- 이는 사용자 입력이 필요한 경우 유휴 시간 후에 표시되는
  -- (순수하게 정보 제공용) 도우미 메시지에도 영향을 미칩니다.
  silent = false,
}

수식어

MiniAlign.config.modifiers는 정렬 프로세스를 관리하는 대화형 사용자 경험을 정의하는 데 사용됩니다. 단일 문자 키와 수식어 함수 값을 가진 테이블입니다.

각 수식어 함수는:

  • 해당 수식어 키가 눌릴 때 호출됩니다.

  • (steps, opts) 시그니처를 가지며 입력을 직접 수정해야 합니다.

예제:

  • 기본 ‘i’ 수식어에 사용되는 수식어 함수:

    function(steps, _)
  table.insert(steps.pre_split, MiniAlign.gen_step.ignore_split())
end

  • 들여쓰기를 유지하는 대신 가장 높은 들여쓰기를 사용하도록 ‘t’ 수식어를 조정합니다:

    require('mini.align').setup({
  modifiers = {
    t = function(steps, _)
      local trim_high = MiniAlign.gen_step.trim('both', 'high')
      table.insert(steps.pre_justify, trim_high)
    end
  }
})

  • ’junegunn/vim-easy-align’에서와 같이 사용 가능한 “justify_side” 옵션 값을 순환하도록 j 수식어를 조정합니다:

    require('mini.align').setup({
  modifiers = {
    j = function(_, opts)
      local next_option = ({
        left = 'center', center = 'right', right = 'none', none = 'left',
      })[opts.justify_side]
      opts.justify_side = next_option or 'left'
    end,
  },
})

옵션

MiniAlign.config.options는 단계의 동작을 제어하는 데 사용되는 옵션의 기본값을 정의합니다.

예제:

  • 초기화 시 가운데 정렬하도록 justify_side = 'center'로 설정합니다.

옵션에 대한 자세한 내용은 MiniAlign.align_strings() 및 기본 주요 단계에 대한 MiniAlign.gen_step 항목을 참조하세요.

단계

MiniAlign.config.steps는 정렬 프로세스 중에 적용될 기본 단계를 정의합니다.

예제:

  • 기본적으로 첫 번째 열 쌍만 정렬합니다:

    local align = require('mini.align')
align.setup({
  steps = {
    pre_justify = { align.gen_step.filter('n == 1') }
  },
})

align_strings()

MiniAlign.align_strings({strings}, {opts}, {steps})

문자열 정렬

정렬 프로세스에 대한 자세한 내용은 MiniAlign-알고리즘을 참조하세요.

매개변수

{strings} (table) 문자열 배열.

{opts} (table|nil) 옵션. 사본이 두 번째 인수로 단계에 전달됩니다. MiniAlign.config.options로 확장됩니다. 다음은 기본 주요 단계를 제어하는 곳입니다:

  • opts.split_pattern - 부분을 나누는 데 사용되는 Lua 패턴.

  • opts.split_exclude_patterns - 무시해야 할 분할 일치 항목.

  • opts.justify_side - 정렬이 수행되어야 할 방향.

  • opts.justify_offsets - 첫 번째 열의 너비를 조정하는 오프셋.

  • opts.merge_delimiter - 병합 시 사용할 구분 기호.

자세한 내용은 해당 기본 단계에 대한 MiniAlign.gen_step 항목을 참조하세요.

{steps} (table|nil) 단계. MiniAlign.config.steps로 확장됩니다. nil 값은 해당 기본 단계로 대체됩니다:

  • split - MiniAlign.gen_step.default_split().

  • justify - MiniAlign.gen_step.default_justify().

  • merge - MiniAlign.gen_step.default_merge().

align_user()

MiniAlign.align_user({mode})

사용자 제공 단계로 현재 영역 정렬

주로 매핑 내부에서 사용되도록 설계되었습니다.

MiniAlign.align_strings()를 사용하고 opts에 다음 옵션을 설정합니다:

  • justify_offsets - 영역의 실제 정렬을 달성하는 데 사용되는 오프셋 배열입니다. 문자 단위 선택의 경우에만 0이 아닌 배열이 됩니다. 첫 번째 문자열의 오프셋은 영역 시작 부분 왼쪽의 접두사 너비로 계산됩니다.

  • region - 현재 영향을 받는 영역(MiniAlign-용어집 참조). 더 고급 단계를 만드는 데 사용할 수 있습니다.

  • mode - 선택 모드(MiniAlign-용어집 참조).

매개변수

{mode} (string) 선택 모드. “char”, “line”, “block” 중 하나.

as_parts()

MiniAlign.as_parts({arr2d})

문자열의 2차원 배열을 부분(parts)으로 변환

이 함수는 입력이 적절한 문자열 2차원 배열인지 확인하고 사본에 메서드를 추가합니다.

클래스

{parts}

필드

{apply} (function) 호출 가능한 f를 인수로 받아 모든 부분에 적용합니다. 호출 가능한 객체는 (s, data) 시그니처를 가져야 합니다. s는 문자열 부분, data는 해당 데이터를 가진 테이블입니다(<row>은 행 번호, <col>은 열 번호를 가짐). 새로운 2차원 배열을 반환합니다.

{apply_inplace} (function) 호출 가능한 f를 인수로 받아 모든 부분에 적용합니다. apply 메서드와 동일한 시그니처를 가져야 합니다. 출력(모두 문자열이어야 함)은 해당 부분 요소에 직접 할당됩니다. 메서드 체이닝을 위해 부분 자체를 반환합니다.

{get_dims} (function) 부분 배열의 차원을 반환합니다: 행의 수와 열의 수(모든 행 중 최대 요소 수)를 가진 <row> 및 <col> 키를 포함하는 테이블입니다.

{group} (function) 제공된 불리언 마스크와 방향(“left”(기본값) 또는 “right”)에 따라 인접한 문자열을 연결합니다. (mask, direction) 시그니처를 가지며 부분을 직접 수정합니다. 메서드 체이닝을 위해 부분 자체를 반환합니다.

예제:

  • 부분: { { "a", "b", "c" }, { "d", "e" }, { "f" } }

  • 마스크: { { false, false, true }, { true, false }, { false } }

  • “left” 방향 결과: { { "abc" }, { "d", "e" }, { "f" } }

  • “right” 방향 결과: { { "ab","c" }, { "de" }, { "f" } }

{pair} (function) 인접한 요소 쌍을 연결합니다. direction(“left”(기본값) 또는 “right”)을 입력으로 받아 교차 마스크에 대해 group()을 적용합니다.

예제:

  • 부분: { { "a", "b", "c" }, { "d", "e" }, { "f" } }

  • “left” 방향 결과: { { "ab", "c" }, { "de" }, { "f" } }

  • “right” 방향 결과: { { "a", "bc" }, { "de" }, { "f" } }

{slice_col} (function) 인덱스 j에 해당하는 열을 반환합니다. 참고: 행마다 열의 수가 다를 경우 배열이 아닐 수 있습니다.

{slice_row} (function) 인덱스 i에 해당하는 행을 반환합니다.

{trim} (function) 요소의 공백을 제거합니다. (direction, indent) 시그니처를 가지며 부분을 직접 수정합니다. 메서드 체이닝을 위해 부분 자체를 반환합니다.

  • direction 가능한 값: “both”(기본값), “left”, “right”, “none”. 어느 쪽에서 공백을 제거할지 정의합니다.

  • indent 가능한 값: “keep”(기본값), “low”, “high”, “remove”. 가능한 들여쓰기(행의 첫 번째 문자열 왼쪽 공백)를 어떻게 처리할지 정의합니다. “keep”은 유지하고, “low”는 모든 들여쓰기를 행들 중 가장 낮은 들여쓰기와 동일하게 만들며, “high”는 가장 높은 들여쓰기로, “remove”는 들여쓰기를 제거합니다.

사용법

parts = MiniAlign.as_parts({ { 'a', 'b' }, { 'c' } })
print(vim.inspect(parts.get_dims())) -- { row = 2, col = 2 }여야 함

parts.apply_inplace(function(s, data)
  return ' ' .. data.row .. s .. data.col .. ' '
end)
print(vim.inspect(parts)) -- { { ' 1a1 ', ' 1b2 ' }, { ' 2c1 ' } }여야 함

parts.trim('both', 'remove').pair()
print(vim.inspect(parts)) -- { { '1a11b2' }, { '2c1' } }여야 함

new_step()

MiniAlign.new_step({name}, {action})

단계 생성

단계는 기본적으로 이름이 지정된 호출 가능한 객체입니다. 이름과 동작이 함께 묶여 있어 대화형 정렬 프로세스 중에 도우미 상태 메시지를 제공할 수 있습니다.

매개변수

{name} (string) 단계 이름.

{action} (function|table) 단계 동작. 호출 가능한 객체여야 합니다(vim.is_callable() 참조).

반환값

(table) 다음 키를 포함하는 테이블: <name>과 name 인수, <action>과 action.

gen_step

MiniAlign.gen_step

공통 동작 단계 생성

함수 요소를 가진 테이블입니다. 실제로 단계를 얻으려면 호출하세요.

각 단계 동작은 (object, opts) 시그니처를 가진 함수입니다. 여기서 object는 부분(parts) 또는 문자열 배열(정렬 프로세스의 어느 단계에 적용되는지에 따라 다름)이고 opts는 옵션 테이블입니다.

default_*로 명명된 요소의 출력은 해당 기본 주요 단계(분할, 조정, 병합)로 사용됩니다. 이들의 모든 동작은 제공된 옵션(두 번째 인수) 값에 따라 달라집니다.

다른 요소의 출력은 단계 생성기 입력 값과 실행 시 제공된 옵션 모두에 따라 달라집니다. 이러한 설계는 주로 그들의 출력이 사전 단계에서 여러 번 사용될 수 있기 때문입니다.

사용법

local align = require('mini.align')
align.setup({
  modifiers = {
    -- 공백과 들여쓰기를 모두 제거하려면 'T' 수식어를 사용하세요
    T = function(steps, _)
      table.insert(steps.pre_justify, align.gen_step.trim('both', 'remove'))
    end,
  },
  options = {
    -- 기본적으로 "right", "left", "right", "left", ... 순으로 정렬합니다
    justify_side = { 'right', 'left' },
  },
  steps = {
    -- 기본적으로 첫 번째 열 쌍만 정렬합니다
    pre_justify = { align.gen_step.filter('n == 1') },
  },
})

gen_step.default_split()

MiniAlign.gen_step.default_split()

기본 분할 단계 생성

출력은 split_exclude_patterns 옵션에 의해 제외되지 않은 split_pattern 옵션의 Lua 패턴 일치 항목을 사용하여 문자열을 나눕니다.

단일 문자열이 분할되는 방식 개요:

  • split_pattern 옵션을 문자열 배열로 변환합니다(문자열은 단일 요소 배열로 변환됨). 변환된 split_pattern 배열보다 더 많은 분할 일치 항목이 있는 경우(거의 항상 그렇음) 이 배열은 재사용됩니다.

  • split_exclude_patterns의 모든 패턴의 모든 일치 항목인 금지된 범위(문자열 내부 간격)를 모두 찾습니다.

  • 다음 패턴에 대한 일치 항목을 찾습니다. 금지된 범위 내에 있지 않은 경우, 앞에 일치하지 않는 부분 문자열과 일치하는 분할을 두 부분으로 추가합니다. 다음 패턴으로 반복합니다.

  • 패턴 일치 항목을 찾을 수 없는 경우 나머지 문자열을 최종 부분으로 추가합니다.

출력은 다음 옵션을 사용합니다(두 번째 인수 opts 테이블의 일부):

  • <split_pattern> - 분할 일치를 감지하고 부분을 생성하는 데 사용되는 문자열 또는 문자열 배열입니다. 기본값: ''(일치 항목 없음, 전체 문자열이 부분으로 사용됨). 예제: '%s+', { '<', '>' }.

  • <split_exclude_patterns> - 일치 항목에서 제외할 영역을 정의하는 문자열 배열입니다. 기본값: {}. 예제: { '".-"', '^%s*#.*' }.

반환값

(table) 이름이 “split”이고 적절한 호출 가능한 동작을 가진 단계입니다.

참고

MiniAlign.gen_step.ignore_split()은 split_exclude_patterns를 많이 사용합니다.

gen_step.default_justify()

MiniAlign.gen_step.default_justify()

기본 조정 단계 생성

출력은 왼쪽 및/또는 오른쪽 공백 패딩을 추가하여 문자열 부분의 열 요소들이 동일한 너비를 갖도록 만듭니다. 어느 쪽을 패딩할지는 justify_side 옵션에 의해 정의됩니다. 첫 번째 열의 너비는 justify_offsets 옵션으로 조정할 수 있습니다.

부분이 조정되는 방식 개요:

  • justify_side 옵션을 문자열 배열로 변환합니다(단일 문자열은 단일 요소 배열로 변환됨). 부분의 열 수와 동일한 길이를 갖도록 이 배열을 재사용합니다.

  • 모든 열에 대해 해당 열에 있는 문자열의 최대 너비를 계산합니다(첫 번째 열 너비에는 justify_offsets의 오프셋을 더함). 참고: 왼쪽 정렬의 경우 마지막 행 요소의 너비는 열 너비에 영향을 주지 않습니다. 이는 주로 패딩되지 않기 때문이며, “일치 항목 없음” 줄을 처리하는 데 도움이 됩니다.

  • 적절한 양의 공백을 추가하여 열 내부의 모든 요소가 동일한 너비를 갖도록 만듭니다. 어느 쪽에 추가할지는 해당 justify_side 배열 요소에 의해 제어됩니다. 참고: 패딩은 공백으로 수행되며, 이는 탭 들여쓰기와 충돌할 수 있습니다.

출력은 다음 옵션을 사용합니다(두 번째 인수 opts 테이블의 일부):

  • <justify_side> - 문자열 또는 문자열 배열입니다. 각 요소는 “left”(오른쪽 패딩), “center”(양쪽 균등 패딩), “right”(왼쪽 패딩), “none”(패딩 없음) 중 하나일 수 있습니다. 기본값: “left”.

  • <justify_offsets> - 행의 숫자 왼쪽 오프셋 배열입니다. 왼쪽 가장자리가 첫 번째 열에 있지 않은 문자 단위 선택의 경우와 같이 동일하지 않은 들여쓰기를 조정하는 데 사용됩니다. 기본값: 0의 배열. 문자 단위 모드에서 대화형 정렬 중에 자동으로 설정됩니다.

반환값

(table) 이름이 “justify”이고 적절한 호출 가능한 동작을 가진 단계입니다.

MiniAlign.gen_step.default_merge()

기본 병합 단계 생성

출력은 부분들의 행 사이에 병합 구분 기호를 배치하여 문자열로 병합합니다.

부분이 문자열 배열로 변환되는 방식 개요:

  • merge_delimiter 옵션을 문자열 배열로 변환합니다(단일 문자열은 단일 요소 배열로 변환됨). 부분의 열 수에서 1을 뺀 길이와 동일하도록 이 배열을 재사용합니다. 또한 들여쓰기에 영향을 주지 않도록 첫 번째 병합 문자의 앞선 공백을 제거할 수 있습니다.

  • 부분에서 빈 문자열을 제외합니다. 이들은 병합 구분 기호의 추가 사용 외에는 출력에 아무것도 더하지 않습니다.

  • 병합 구분 기호 배열을 끼워 넣어 각 행을 연결합니다.

출력은 다음 옵션을 사용합니다(두 번째 인수 opts 테이블의 일부):

  • <merge_delimiter> - 문자열 또는 문자열 배열입니다. 기본값: ''. 예제: ' ', { '', ' ' }.

반환값

(table) 이름이 “merge”이고 적절한 호출 가능한 동작을 가진 단계입니다.

gen_step.filter()

MiniAlign.gen_step.filter({expr})

필터 단계 생성

제공된 Lua 문자열 표현식에서 함수 서술어(predicate)를 구성하고 모든 부분 요소에 대해 이를 평가하는 단계를 만듭니다.

필터링 수행 방식 개요:

  • Lua 필터링 표현식을 수동으로 생성된 컨텍스트(일부 특정 변수가 설정됨)에서 평가할 수 있는 함수 서술어로 변환합니다.

  • 특별 변수가 특정 값으로 설정된(다음 섹션 참조) 2차원 배열의 각 요소에 서술어를 적용하여 부분의 불리언 마스크를 계산합니다.

  • 계산된 마스크로 부분을 그룹화합니다. MiniAlign.as_parts()의 부분의 group() 메서드를 참조하세요.

표현식에서 사용할 수 있는 특별 변수:

  • <row> - 현재 요소의 행 번호.

  • <ROW> - 부분의 총 행 수.

  • <col> - 현재 요소의 열 번호.

  • <COL> - 현재 행의 총 열 수.

  • <s> - 현재 요소의 문자열 값.

  • <n> - 현재 요소의 열 쌍 번호. 패턴 분할 결과로 필터링할 때 유용합니다.

  • <N> - 현재 행의 총 열 쌍 수.

  • 전역 테이블 _G로부터의 모든 변수.

팁:

  • 이 일반적인 필터링 접근 방식은 정렬에서 특정 부분을 포함하거나 제외하는 데 모두 사용할 수 있습니다. 예제:

    • 두 번째 행을 제외한 모든 부분을 정렬하려면 row ~= 2를 사용합니다.

    • 첫 번째 열 쌍으로만 정렬하려면 n == 1을 사용합니다.

  • 마지막 등호로 필터링하는 것은 보통 n >= (N - 1)로 수행할 수 있습니다(보통 등호 오른쪽에 무언가가 있기 때문입니다).

매개변수

{expr} (string) 서술어로 사용될 문자열 형태의 Lua 표현식.

반환값

(table|nil) 이름이 “filter”이고 적절한 호출 가능한 동작을 가진 단계입니다.
