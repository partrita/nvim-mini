mini.move 문서

_ ’mini.nvim’의 main 브랜치에서 생성됨 _

mini.move 선택 영역을 원하는 방향으로 이동

MIT 라이선스 Copyright (c) 2023 Evgeni Chasnovski

모듈

기능:

  • 두 가지 모드에서 작동합니다:

    • 비주얼 모드(Visual mode). 텍스트를 선택(v로 문자 단위, V로 줄 단위, CTRL-V로 블록 단위)하고 사용자 정의 매핑을 눌러 네 방향(왼쪽, 오른쪽, 아래, 위)으로 이동합니다. 비주얼 모드는 유지됩니다.

    • 노멀 모드(Normal mode). 사용자 정의 매핑을 눌러 현재 줄을 네 방향(왼쪽, 오른쪽, 아래, 위)으로 이동합니다.

    • 줄 단위 이동 시 특별한 처리:

      • 수직 이동 시 =을 사용하여 자동으로 들여쓰기가 조정됩니다.

      • 수평 이동은 > / <를 사용한 개선된 들여쓰기/내어쓰기입니다.

      • 커서가 선택 영역과 함께 이동합니다.

  • 이동을 위한 매핑과 Lua 함수를 모두 제공합니다. MiniMove.move_selection() 및 MiniMove.move_line()을 참조하세요.

  • v:count를 지원합니다. 이동 매핑 앞에 숫자를 입력하여 명령의 효과를 배가할 수 있습니다.

  • 방향에 관계없이 연속된 모든 이동은 단일 u 키로 실행 취소할 수 있습니다.

  • 수직 이동 시 선호하는 열(column) 위치를 존중합니다. 커서가 이동하는 방식과 동일하게 선택 영역을 수직으로 이동합니다 (대상 줄에 해당 열이 없는 경우 엄격하게 수직으로 이동하지 않을 수 있음).

참고 사항:

  • 선택 영역을 현재 줄 밖으로 이동하는 것은 허용하지 않습니다 (의도된 설계).

설정

이 모듈은 require('mini.move').setup({})을 통한 설정이 필요합니다 ({}를 사용자 config 테이블로 대체). 그러면 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniMove가 생성됩니다 (예: :lua MiniMove.*).

사용 가능한 설정 옵션은 MiniMove.config를 참조하세요.

MiniMove.config와 동일한 구조를 가진 vim.b.minimove_config를 사용하여 버퍼별로 런타임 설정(단, config.mappings 제외)을 재정의할 수 있습니다. 자세한 내용은 mini.nvim-buffer-local-config를 참조하세요.

비교

  • matze/vim-move:

    • 문자 단위 및 블록 단위 선택 영역의 수직 이동을 지원하지 않지만, ’mini.move’는 지원합니다.

    • 현재 문자의 수평 이동 대신 현재 줄의 수평 이동을 지원하지 않지만, ’mini.move’는 현재 줄의 수평 이동을 지원하며 현재 문자의 이동은 지원하지 않습니다.

    • 반 페이지 이동과 같은 특정 이동에 대한 추가 기능이 있지만, ’mini.move’는 의도적으로 이를 지원하지 않습니다.

  • booperlv/nvim-gomove:

    • 문자 단위 비주얼 선택 영역에서의 이동을 지원하지 않지만, ’mini.move’는 지원합니다.

    • 텍스트 이동 외에 복제와 같은 추가 기능이 있지만, ’mini.move’는 이동 기능에만 집중합니다.

비활성화

비활성화하려면 vim.g.minimove_disable(전역) 또는 vim.b.minimove_disable(버퍼별)을 true로 설정하세요. 다양한 시나리오와 사용자 정의 의도를 고려하여 모듈 기능 비활성화에 대한 정확한 규칙을 작성하는 것은 사용자의 몫으로 남겨둡니다. 일반적인 방법은 mini.nvim-disabling-recipes를 참조하세요.

setup()

MiniMove.setup({config})

모듈 설정

매개변수

{config} (table|nil) 모듈 설정 테이블. MiniMove.config를 참조하세요.

사용법

require('mini.move').setup() -- 기본 설정 사용
-- 또는
require('mini.move').setup({}) -- {}를 사용자 설정 테이블로 대체

config

MiniMove.config

기본값

MiniMove.config = {
  -- 모듈 매핑. 비활성화하려면 `''`(빈 문자열)을 사용하세요.
  mappings = {
    -- 비주얼 모드에서 비주얼 선택 영역 이동. 기본값은 Alt (Meta) + hjkl입니다.
    left = '<M-h>',
    right = '<M-l>',
    down = '<M-j>',
    up = '<M-k>',

    -- 노멀 모드에서 현재 줄 이동
    line_left = '<M-h>',
    line_right = '<M-l>',
    line_down = '<M-j>',
    line_up = '<M-k>',
  },

  -- 이동 동작을 제어하는 옵션
  options = {
    -- 줄 단위 수직 이동 중 자동으로 선택 영역 들여쓰기 조정
    reindent_linewise = true,
  },
}

매개변수

다른 매핑 선택지 예시:

-- 비주얼 선택 영역 이동을 위해 `HJKL` 사용 (비주얼 모드에서 H, L, J 재정의)
require('mini.move').setup({
  mappings = {
    left  = 'H',
    right = 'L',
    down  = 'J',
    up    = 'K',
  }
})

-- Shift + 화살표 키
require('mini.move').setup({
  mappings = {
    left  = '<S-left>',
    right = '<S-right>',
    down  = '<S-down>',
    up    = '<S-up>',

    line_left  = '<S-left>',
    line_right = '<S-right>',
    line_down  = '<S-down>',
    line_up    = '<S-up>',
  }
})

move_selection()

MiniMove.move_selection({direction}, {opts})

현재 줄 내에서 비주얼 선택 영역을 원하는 방향으로 이동합니다

비주얼 모드에서 비주얼 선택 영역 이동을 담당하는 주요 함수입니다.

참고 사항:

  • 줄 단위 모드에서의 수직 이동 후에는 v_=를 사용한 자동 들여쓰기 조정이 이어집니다.

  • 줄 단위 모드에서의 수평 이동은 v_< 및 v_>와 동일합니다.

매개변수

{direction} (string) “left”, “down”, “up”, “right” 중 하나.

{opts} (table|nil) 옵션. MiniMove.config의 options와 동일한 구조(기본값 포함)이며, 다음 추가 필드를 허용합니다:

  • <n_times> (number) - 이동을 시도할 횟수. 기본값: v:count1.

move_line()

MiniMove.move_line({direction}, {opts})

현재 줄을 원하는 방향으로 이동합니다

노멀 모드에서 현재 줄 이동을 담당하는 주요 함수입니다.

참고 사항:

  • 수직 이동 후에는 v_=를 사용한 자동 들여쓰기 조정이 이어집니다.

  • 수평 이동은 << 및 >>와 거의 동일하지만, v:count 처리가 다릅니다 (줄 수를 수정하는 대신 들여쓰기 효과를 배가합니다).

매개변수

{direction} (string) “left”, “down”, “up”, “right” 중 하나.

{opts} (table|nil) 옵션. MiniMove.config의 options와 동일한 구조(기본값 포함)이며, 다음 추가 필드를 허용합니다:

  • <n_times> (number) - 이동을 시도할 횟수. 기본값: v:count1.
