mini.sessions 세션 관리

MIT 라이선스 Copyright (c) 2021 Evgeni Chasnovski

모듈

세션을 읽고, 쓰고, 삭제합니다. :mksession을 사용하므로 ’sessionoptions’가 완전히 존중됩니다. 이는 mhinz/vim-startify 세션 관리의 Lua 대체제로 설계되었습니다 (기존 세션과 호환됨). 설정된 디렉토리의 전역(global) 세션과 현재 디렉토리의 로컬(local) 세션을 모두 지원합니다.

주요 디자인 아이디어:

  • 세션은 읽을 수 있는 파일(:mksession의 결과물)로 표현됩니다. 두 가지 종류의 세션이 있습니다:

    • 전역(Global): 설정된 디렉토리 내의 모든 파일.

    • 로컬(Local): 현재 작업 디렉토리(getcwd()) 내의 설정된 파일.

  • 모든 세션 파일은 MiniSessions.setup() 도중과 관련 동작(read, delete, select) 도중에 감지되며, 파일 이름이 세션 이름(확장자 포함 가능)으로 사용됩니다.

  • 새로운 세션의 자동 생성은 지원하지 않습니다. MiniSessions.write()를 수동으로 사용하세요.

  • 감지된 세션에 대한 정보는 별도의 테이블(MiniSessions.detected)에 저장되며 이 테이블에서만 작동합니다. 즉, 정보가 변경되어도 다음 감지 전까지는 효과가 없습니다. 혼란을 피하기 위해 세션 파일을 읽고 쓰는 데 :mksession / :source를 직접 사용하지 마세요.

주요 기능:

  • Neovim이 다른 무언가를 보여줄 의도 없이 실행된 경우, 기본 세션(감지된 경우 로컬, 그렇지 않으면 가장 최근에 작성된 전역 세션)을 자동으로 읽습니다(Autoread).

  • 세션을 벗어나기 전에(Neovim 종료 또는 다른 세션 읽기) 현재 읽은 세션을 자동으로 저장합니다(Autowrite).

  • 모든 동작에 대해 설정 가능한 심각도 레벨을 지원합니다.

설정

이 모듈은 require('mini.sessions').setup({})을 통한 설정이 필요합니다 ({}를 원하는 config 테이블로 교체하세요). 이를 통해 스크립팅이나 수동으로 사용할 수 있는 전역 Lua 테이블 MiniSessions가 생성됩니다 ( :lua MiniSessions.* 사용).

사용 가능한 설정값은 MiniSessions.config를 참조하세요.

이 모듈은 버퍼 로컬 설정의 이점이 없으므로 vim.b.minisessions_config를 사용해도 효과가 없습니다.

비활성화

핵심 기능을 비활성화하려면 vim.g.minisessions_disable(전역) 또는 vim.b.minisessions_disable(버퍼용)을 true로 설정하세요. 다양한 시나리오와 커스터마이징 의도를 고려할 때, 모듈 기능을 비활성화하기 위한 정확한 규칙을 작성하는 것은 사용자의 몫입니다. 일반적인 방법은 mini.nvim-disabling-recipes를 참조하세요.

setup()

MiniSessions.setup({config})

모듈 설정

매개변수

{config} (table|nil) 모듈 설정 테이블입니다. MiniSessions.config를 참조하세요.

사용법

require('mini.sessions').setup() -- 기본 설정 사용
-- 또는
require('mini.sessions').setup({}) -- {}를 원하는 설정 테이블로 교체

config

MiniSessions.config

기본값

MiniSessions.config = {
  -- 파일 인자 없이 Neovim을 열었을 때 기본 세션을 읽을지 여부
  autoread = false,

  -- 현재 읽은 세션을 벗어나기 전에 자동으로 저장할지 여부
  autowrite = true,

  -- 전역 세션이 저장되는 디렉토리 (비활성화하려면 `''` 사용)
  directory = --<|stdpath()|에서 가져온 사용자 데이터 디렉토리의 "session" 하위 디렉토리>,

  -- 로컬 세션을 위한 파일 (비활성화하려면 `''` 사용)
  file = 'Session.vim',

  -- 잠재적으로 해로울 수 있는 동작을 강제할지 여부 (기능에 따라 의미가 다름)
  force = { read = false, write = true, delete = false },

  -- 동작에 대한 후크(Hook) 함수. 기본값 `nil`은 '아무것도 하지 않음'을 의미합니다.
  -- 활성 세션 데이터를 인자로 하는 테이블을 받습니다.
  hooks = {
    -- 성공적인 동작 전
    pre = { read = nil, write = nil, delete = nil },
    -- 성공적인 동작 후
    post = { read = nil, write = nil, delete = nil },
  },

  -- 동작 후 세션 경로를 출력할지 여부
  verbose = { read = false, write = true, delete = true },
}

detected

MiniSessions.detected

감지된 세션 테이블입니다. 키는 세션 이름을 나타냅니다. 값은 현재 다음과 같은 필드(변경될 수 있음)를 가진 세션 정보 테이블입니다:

  • <modify_time> (number) 세션 파일의 수정 시간( getftime() 참조).

  • <name> (string) 세션 이름 (테이블 키와 동일해야 함).

  • <path> (string) 세션 파일의 전체 경로.

  • <type> (string) 세션 유형 (‘global’ 또는 ‘local’).

read()

MiniSessions.read({session_name}, {opts})

감지된 세션 읽기

수행 동작:

  • 활성 세션이 있고 MiniSessions.config에서 autowrite가 true인 경우, MiniSessions.write()를 사용하여 저장합니다.

  • :bwipeout을 사용하여 현재의 모든 버퍼를 삭제합니다. 이는 대상 세션에서 버퍼를 올바르게 복구하는 데 필요합니다. force가 true가 아니면, 저장되지 않은 버퍼가 있는지 미리 확인하고 있으면 중단합니다.

  • 제공된 이름의 세션 파일을 불러옵니다(source).

매개변수

{session_name} (string|nil) 읽을 감지된 세션 파일의 이름입니다. 기본값: nil (기본 세션 사용: 감지된 경우 로컬 세션, 그렇지 않으면 최신 세션( MiniSessions.get_latest() 참조)).

{opts} (table|nil) 옵션 테이블입니다. 현재 허용되는 키:

  • <force> (저장되지 않은 버퍼를 삭제할지 여부; 기본값: MiniSessions.config.force.read).

  • <verbose> (동작 후 세션 경로를 출력할지 여부; 기본값 MiniSessions.config.verbose.read).

  • <hooks> (성공적인 읽기 전후에 세션 데이터를 인자로 실행될 <pre> 및 <post> 함수 후크 테이블; MiniSessions.config.hooks.pre.read 및 MiniSessions.config.hooks.post.read를 재정의함).

write()

MiniSessions.write({session_name}, {opts})

세션 쓰기(저장)

수행 동작:

  • 제공된 세션 이름의 파일이 이미 존재하는지 확인합니다. 존재하고 force가 true가 아니면 중단합니다.

  • :mksession을 사용하여 session_name이라는 파일로 세션을 저장합니다. 디렉토리는 세션 유형에 따라 결정됩니다:

    • session_name이 nil이고 현재 읽은 세션이 있는 경우 v:this_session 위치에 저장합니다.

    • session_name이 MiniSessions.config.file과 같으면(로컬 세션) 현재 작업 디렉토리(getcwd())에 저장합니다.

    • 그 외의 경우(전역 세션) MiniSessions.config.directory에 저장합니다.

  • MiniSessions.detected를 업데이트합니다.

매개변수

{session_name} (string|nil) 저장할 세션 파일의 이름입니다. 기본값: nil (현재 읽은 세션 사용(v:this_session)).

{opts} (table|nil) 옵션 테이블입니다. 현재 허용되는 키:

  • <force> (세션 파일의 존재 여부를 무시할지 여부; 기본값: MiniSessions.config.force.write).

  • <verbose> (동작 후 세션 경로를 출력할지 여부; 기본값 MiniSessions.config.verbose.write).

  • <hooks> (성공적인 저장 전후에 세션 데이터를 인자로 실행될 <pre> 및 <post> 함수 후크 테이블; MiniSessions.config.hooks.pre.write 및 MiniSessions.config.hooks.post.write를 재정의함).

delete()

MiniSessions.delete({session_name}, {opts})

감지된 세션 삭제

수행 동작:

  • 세션 이름이 현재 세션인지 확인합니다. 현재 세션이고 force가 true가 아니면 중단합니다.

  • 세션을 삭제합니다.

  • MiniSessions.detected를 업데이트합니다.

매개변수

{session_name} (string|nil) 삭제할 감지된 세션 파일의 이름입니다. 기본값: nil (현재 읽은 세션의 이름(v:this_session) 사용).

{opts} (table|nil) 옵션 테이블입니다. 현재 허용되는 키:

  • <force> (현재 세션의 삭제를 허용할지 여부; 기본값: MiniSessions.config.force.delete).

  • <verbose> (동작 후 세션 경로를 출력할지 여부; 기본값 MiniSessions.config.verbose.delete).

  • <hooks> (성공적인 삭제 전후에 세션 데이터를 인자로 실행될 <pre> 및 <post> 함수 후크 테이블; MiniSessions.config.hooks.pre.delete 및 MiniSessions.config.hooks.post.delete를 재정의함).

select()

MiniSessions.select({action}, {opts})

대화형으로 세션을 선택하고 동작 수행

참고: vim.ui.select() 함수를 사용합니다. 더 사용자 친화적인 경험을 위해 이 함수를 재정의하세요 (예: MiniPick.ui_select() 참조).

매개변수

{action} (string|nil) 수행할 동작입니다. “read” (기본값), “write”, “delete” 중 하나여야 합니다.

{opts} (table|nil) 지정된 동작에 대한 옵션입니다.

get_latest()

MiniSessions.get_latest()

가장 최근에 감지된 세션의 이름 가져오기

getftime()으로 확인했을 때 수정 시간이 가장 최근인 세션입니다.

반환

(string|nil) 가장 최근 세션의 이름 또는 세션이 없는 경우 nil.
