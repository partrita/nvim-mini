mini.starter 문서

mini.nvim의 main 브랜치에서 생성됨

mini.starter 시작 화면

MIT 라이선스 Copyright (c) 2021 Evgeni Chasnovski

모듈

표시되는 항목들은 무엇을 수행하고 어떻게 보일지(합리적인 기본값 포함)를 완전히 커스터마이징할 수 있습니다. 항목 선택은 즉각적인 시각적 피드백과 함께 접두사 쿼리를 사용하여 수행할 수 있습니다.

주요 디자인 아이디어:

  • 모든 사용 가능한 동작은 항목 내부에 정의됩니다. 각 항목은 다음 정보를 가져야 합니다:

    • <action> - 항목이 선택되었을 때 실행되는 함수 또는 vim.cmd()용 문자열입니다. 빈 문자열은 자리 표시자인 “비활성” 항목이 됩니다.

    • <name> - 표시되고 선택에 사용될 문자열입니다.

    • <section> - 항목이 속한 섹션을 나타내는 문자열입니다. MiniStarter.sections에 미리 구성된 전체 섹션들이 있습니다.

  • 정규화된 항목 배열로 변환될 수 있는 배열을 제공하여 표시할 항목을 구성합니다. 제공된 항목이 어떻게 정규화되는지에 대해서는 MiniStarter.refresh()를 참조하세요.

  • 콘텐츠 후크를 제공하여 최종 모양을 수정합니다. 콘텐츠 후크는 버퍼 콘텐츠(MiniStarter.get_content() 참조)와 식별자를 입력으로 받아 버퍼 콘텐츠를 출력으로 반환하는 함수입니다. MiniStarter.gen_hook에 미리 구성된 콘텐츠 후크 생성기들이 있습니다.

  • 항목 선택은 두 가지 방법으로 수행할 수 있습니다:

    • 접두사 쿼리를 입력하여 이름(대소문자 무시)이 일치하는 항목을 필터링합니다. 표시되는 정보는 각 문자가 입력될 때마다 업데이트됩니다. 모든 항목에 대해 고유한 접두사가 강조 표시됩니다.

    • 위/아래 화살표를 사용하고 Enter 키를 누릅니다.

  • 여러 개의 Starter 버퍼를 동시에 열 수 있도록 허용합니다.

수행하지 않는 것:

  • 항목에 대한 퍼지(fuzzy) 쿼리는 지원하지 않습니다. 그리고 앞으로도 지원하지 않을 것입니다.

설정

이 모듈은 require('mini.starter').setup({})을 통한 설정이 필요합니다({}를 config 테이블로 교체하세요). 이는 스크립팅이나 수동으로(:lua MiniStarter.*를 통해) 사용할 수 있는 전역 Lua 테이블 MiniStarter를 생성합니다.

config 구조와 기본값은 MiniStarter.config를 참조하세요. 일부 구성 예시(‘vim-startify’ 및 ’dashboard-nvim’과 유사한 예시 포함)는 MiniStarter-example-config를 참조하세요.

런타임 설정은 vim.b.ministarter_config를 통해 버퍼 로컬로 재정의할 수 있으며, 이는 MiniStarter.config와 동일한 구조를 가져야 합니다. 자세한 내용은 mini.nvim-buffer-local-config를 참조하세요. 참고: vim.b.ministarter_config는 현재 버퍼에서 Starter 버퍼로 복사되어 완전한 커스터마이징을 허용합니다.

모듈이 에러가 아닌 피드백을 표시하지 않게 하려면 config.silent = true로 설정하세요.

하이라이트 그룹

  • MiniStarterCurrent - 현재 항목.

  • MiniStarterFooter - 푸터(footer) 단위.

  • MiniStarterHeader - 헤더(header) 단위.

  • MiniStarterInactive - 비활성 항목.

  • MiniStarterItem - 항목 이름.

  • MiniStarterItemBullet - MiniStarter.gen_hook.adding_bullet()의 단위.

  • MiniStarterItemPrefix - 항목의 고유한 쿼리.

  • MiniStarterSection - 섹션 단위.

  • MiniStarterQuery - 활성 항목의 현재 쿼리.

하이라이트 그룹을 변경하려면 nvim_set_hl()을 사용하여 직접 설정하세요.

비활성화

핵심 기능을 비활성화하려면 vim.g.ministarter_disable(전역) 또는 vim.b.ministarter_disable(버퍼용)을 true로 설정하세요. 다양한 시나리오와 커스터마이징 의도를 고려하여 모듈 기능을 비활성화하기 위한 정확한 규칙 작성은 사용자에게 맡겨집니다. 일반적인 레시피는 mini.nvim-disabling-recipes를 참조하세요.

구성 예시

’mhinz/vim-startify’와 유사함

local starter = require('mini.starter')
starter.setup({
  evaluate_single = true,
  items = {
    starter.sections.builtin_actions(),
    starter.sections.recent_files(10, false),
    starter.sections.recent_files(10, true),
    -- 'mini.sessions'를 설정한 경우 사용하세요
    starter.sections.sessions(5, true)
  },
  content_hooks = {
    starter.gen_hook.adding_bullet(),
    starter.gen_hook.indexing('all', { 'Builtin actions' }),
    starter.gen_hook.padding(3, 2),
  },
})

’glepnir/dashboard-nvim’과 유사함

local starter = require('mini.starter')
starter.setup({
  items = {
    starter.sections.telescope(),
  },
  content_hooks = {
    starter.gen_hook.adding_bullet(),
    starter.gen_hook.aligning('center', 'center'),
  },
})

기능 데모

local my_items = {
  { name = 'Echo random number', action = 'lua print(math.random())', section = 'Section 1' },
  function()
    return {
      { name = 'Item #1 from function', action = [[echo 'Item #1']], section = 'From function' },
      { name = 'Placeholder (always inactive) item', action = '', section = 'From function' },
      function()
        return {
          name = 'Item #1 from double function',
          action = [[echo 'Double function']],
          section = 'From double function',
        }
      end,
    }
  end,
  { name = [[Another item in 'Section 1']], action = 'lua print(math.random() + 10)', section = 'Section 1' },
}

local footer_n_seconds = (function()
  local timer = vim.loop.new_timer()
  local n_seconds = 0
  timer:start(0, 1000, vim.schedule_wrap(function()
    if vim.bo.filetype ~= 'ministarter' then
      timer:stop()
      return
    end
    n_seconds = n_seconds + 1
    MiniStarter.refresh()
  end))

  return function()
    return '열린 후 경과 시간(초): ' .. n_seconds
  end
end)()

local hook_top_pad_10 = function(content)
  -- 상단 여백 추가
  for _ = 1, 10 do
    -- 시작 부분에 단일 콘텐츠 단위가 있는 라인 삽입
    table.insert(content, 1, { { type = 'empty', string = '' } })
  end
  return content
end

local starter = require('mini.starter')
starter.setup({
  items = my_items,
  footer = footer_n_seconds,
  content_hooks = { hook_top_pad_10 },
})

라이프사이클

  • MiniStarter.open()으로 엽니다. 여기에는 적절한 옵션, 매핑, 동작을 가진 버퍼를 생성하고; MiniStarter.refresh()를 호출하며; MiniStarterOpened User 이벤트를 발생시키는 과정이 포함됩니다.

  • 사용자가 항목을 선택할 때까지 기다립니다. 이는 다음 로직을 사용하여 수행됩니다:

    • MiniStarter.config.query_updaters에 정의된 문자를 입력하면 쿼리가 업데이트됩니다. 자세한 내용은 MiniStarter.add_to_query()를 참조하세요.

    • <BS> 키는 쿼리의 마지막 문자를 삭제합니다.

    • <Down>/<Up>, <C-n>/<C-p>, <M-j>/<M-k> 키는 현재 항목을 이동합니다.

    • <CR> 키는 현재 항목의 동작을 실행합니다.

    • <C-c> 키는 Starter 버퍼를 닫습니다.

  • 적절한 경우( <CR> 키 입력 후 또는 항목이 하나만 있고 MiniStarter.config.evaluate_single이 true일 때) 현재 항목을 평가합니다. 이는 항목의 action을 실행합니다.

require('mini.starter').setup() -- 기본 설정 사용

config

MiniStarter.config

기본값

MiniStarter.config = {
  -- VimEnter 시 Starter 버퍼를 열지 여부. Neovim이 다른 것을 보여주려는
  -- 의도로 시작된 경우에는 열리지 않습니다.
  autoopen = true,

  -- 단일 활성 항목의 동작을 바로 평가할지 여부
  evaluate_single = false,

  -- 표시할 항목들. 다음 요소들을 가진 배열이어야 합니다:
  -- - 항목(Item): <action>, <name>, <section> 키를 가진 테이블.
  -- - 함수: 이 세 가지 카테고리 중 하나를 반환해야 함.
  -- - 배열: 이 세 가지 유형(항목, 배열, 함수)의 요소들.
  -- `nil`(기본값)인 경우 기본 항목들이 사용됩니다(|mini.starter| 참조).
  items = nil,

  -- 항목 앞에 표시될 헤더. `tostring`을 통해 단일 문자열로 변환됩니다
  -- (여러 줄을 표시하려면 `\n` 사용). 함수인 경우 먼저 평가됩니다.
  -- `nil`(기본값)인 경우 정중한 인사말이 사용됩니다.
  header = nil,

  -- 항목 뒤에 표시될 푸터. `tostring`을 통해 단일 문자열로 변환됩니다
  -- (여러 줄을 표시하려면 `\n` 사용). 함수인 경우 먼저 평가됩니다.
  -- `nil`(기본값)인 경우 기본 사용법 도움말이 표시됩니다.
  footer = nil,

  -- 초기 콘텐츠에 순차적으로 적용될 함수 배열.
  -- 각 함수는 Starter 버퍼용 콘텐츠를 인자로 받아 반환해야 합니다
  -- (|mini.starter| 및 |MiniStarter.get_content()| 참조).
  content_hooks = nil,

  -- 쿼리를 업데이트할 문자들. 각 문자는 전역 매핑을 재정의하는
  -- 특별한 버퍼 매핑을 갖게 됩니다. 명령 모드로 들어갈 수 있게 하는
  -- `:`를 추가하지 않도록 주의하세요.
  query_updaters = 'abcdefghijklmnopqrstuvwxyz0123456789_-.',

  -- 에러가 아닌 피드백 표시를 비활성화할지 여부
  silent = false,
}

open()

MiniStarter.open({buf_id})

Starter 버퍼 열기

  • 필요한 경우 버퍼를 생성하고 해당 버퍼로 이동합니다.

  • 버퍼 옵션을 설정합니다. 엄청난 속도 향상을 위해 설정은 :noautocmd와 함께 수행됩니다.

  • 버퍼 매핑을 설정합니다. 기본 매핑(mini.starter의 “Starter 버퍼의 라이프사이클”에 설명됨) 외에도, MiniStarter.config.query_updaters의 모든 문자를 MiniStarter.add_to_query()를 통해 자신을 쿼리에 추가하도록 매핑합니다.

  • MiniStarter.refresh()로 버퍼를 채웁니다.

  • Starter 버퍼가 열릴 때 동작할 수 있도록 커스텀 MiniStarterOpened 이벤트를 발생시킵니다. autocmd User MiniStarterOpened <your command>와 같이 사용하세요.

참고: 자동 명령(autocommand)에서 완전히 사용하려면 autocmd-nested를 사용하세요. 예시:

local starter_open = function() MiniStarter.open() end
local au_opts = { nested = true, callback = starter_open }
vim.api.nvim_create_autocmd('TabNewEntered', au_opts)

매개변수

{buf_id} (number|nil) 열고자 하는 유효한 기존 버퍼의 식별자(bufnr() 참조). 기본값: 새로 생성합니다.

refresh()

MiniStarter.refresh({buf_id})

Starter 버퍼 새로고침

  • MiniStarter.config.items 정규화:

    • 평탄화(Flatten): 요소를 재귀적으로(깊이 우선 방식) 파싱합니다. 함수가 발견되면 이를 실행하고 그 출력을 계속 파싱합니다(이는 실제로 필요할 때까지 항목 수집을 미룰 수 있게 해줍니다). 적절한 항목(action, name, section 필드를 가진 테이블)이 발견되면 출력에 추가합니다.

    • 정렬(Sort): 먼저 섹션별로 정렬한 다음 항목 ID별로 정렬합니다(둘 다 나타나는 순서대로).

  • MiniStarter.config.header 및 MiniStarter.config.footer를 \n에서 분할하여 여러 줄로 정규화합니다. 함수인 경우 먼저 평가합니다.

  • 초기 버퍼 콘텐츠를 생성합니다(버퍼 콘텐츠에 대한 설명은 MiniStarter.get_content() 참조). 이는 단일 콘텐츠 단위를 가진 콘텐츠 라인들로 구성됩니다:

    • 첫 번째 라인들은 정규화된 헤더의 문자열을 포함합니다.

    • 본문은 정규화된 항목들을 위한 것입니다. 섹션 이름은 빈 라인이 앞에 오는 자체 라인을 갖습니다.

    • 마지막 라인들은 정규화된 푸터의 개별 문자열을 포함합니다.

  • MiniStarter.config.content_hooks의 후크를 콘텐츠에 순차적으로 적용합니다. 모든 후크는 (content, buf_id) 시그니처로 적용됩니다. 한 후크의 출력이 다음 후크의 첫 번째 인자로 사용됩니다.

  • MiniStarter.content_to_items()를 사용하여 콘텐츠에서 최종 항목들을 수집합니다.

  • MiniStarter.content_to_lines()를 사용하여 콘텐츠를 버퍼 라인으로 변환하고 버퍼에 추가합니다.

  • 콘텐츠 단위의 하이라이트를 추가합니다.

  • 커서 위치를 조정합니다.

  • 현재 쿼리를 생성합니다. 이는 일부 항목을 “비활성”으로 표시하고 “활성” 항목에서 현재 쿼리의 하이라이트를 업데이트하게 됩니다.

참고: 이 함수는 더 반응적인 동작을 위해 매번 VimResized 시에 실행됩니다.

매개변수

{buf_id} (number|nil) 유효한 Starter 버퍼의 버퍼 식별자. 기본값: 현재 버퍼.

mini.sessions 세션이 포함된 섹션

세션은 MiniSessions.detected에서 가져옵니다. 참고:

  • “‘mini.sessions’ is not set up”이 표시된다면 require('mini.sessions').setup()을 호출하지 않았음을 의미합니다.

  • “There are no detected sessions in ‘mini.sessions’”가 표시된다면 현재 세션 디렉토리에 세션이 없음을 의미합니다. 세션을 생성하거나 세션 파일이 저장된 다른 디렉토리를 제공하세요(MiniSessions.setup() 참조).

  • 로컬 세션(감지된 경우)은 항상 처음에 표시됩니다.

매개변수

{n} (number|nil) 반환할 항목 수. 기본값: 5.

{recent} (boolean|nil) 최근 세션을 사용할지 여부(이름순 정렬 대신). 기본값: true.

기본적으로 이는 출력 라인이 특정 방식으로 정렬되어 보이도록 MiniStarter.gen_hook.padding()을 위한 왼쪽 및 상단 패딩을 계산합니다.

{vertical} (string|nil) “top”, “center”, “bottom” 중 하나. 기본값: “top”.

get_content()

MiniStarter.get_content({buf_id})

Starter 버퍼의 콘텐츠 가져오기

일반적으로 버퍼 콘텐츠는 “2차원 배열”(요소 수가 다를 수 있으므로 실제로는 “2차원 리스트”) 형태의 테이블입니다:

  • 각 요소는 하나의 버퍼 라인에 표시될 콘텐츠 단위 배열인 콘텐츠 라인을 나타냅니다.

  • 각 콘텐츠 단위는 최소한 다음 요소를 포함하는 테이블입니다:

    • “type” - 콘텐츠의 유형을 나타내는 문자열입니다. “item”, “section”, “header”, “footer”, “empty” 등.

    • “string” - 표시될 문자열입니다. 빈 문자열일 수 있습니다.

    • “hl” - 콘텐츠 문자열에 적용될 하이라이트입니다. 하이라이트가 없는 경우 nil일 수 있습니다.

콘텐츠를 버퍼 라인으로 변환하려면 MiniStarter.content_to_lines()를, 파싱된 항목 리스트로 변환하려면 MiniStarter.content_to_items()를 참조하세요.

참고:

  • 유형이 “item”인 콘텐츠 단위는 해당 단위가 나타내는 항목에 대한 모든 정보를 담은 item 요소도 갖습니다. 이러한 요소들은 쿼리에 사용될 항목 배열을 생성하는 데 직접 사용됩니다.

매개변수

{buf_id} (number|nil) 유효한 Starter 버퍼의 버퍼 식별자. 기본값: 현재 버퍼.

content_coords()

MiniStarter.content_coords({content}, {predicate})

콘텐츠를 순회하기 위한 헬퍼

기본적으로 이는 콘텐츠 “2차원 배열”을 (깊이 우선 방식; 위에서 아래로, 왼쪽에서 오른쪽으로) 순회하며 predicate가 참인 단위의 “좌표(coordinates)”를 반환합니다.

매개변수

{content} (table|nil) 콘텐츠 “2차원 배열”. 기본값: 현재 버퍼의 콘텐츠.

{predicate} (function|string|nil) 단위를 필터링할 서술어. 다음과 같은 경우:

  • 함수인 경우, 단위를 입력으로 평가합니다.

  • 문자열인 경우, 단위가 해당 유형을 가졌는지 확인합니다(특정 유형의 단위를 쉽게 가져올 수 있게 함).

  • nil인 경우, 모든 단위가 유지됩니다.

반환

(table) 결과 단위들의 좌표 배열. 각 좌표는 <line> 및 <unit> 키를 가진 테이블입니다. 좌표 c에서 실제 단위를 가져오려면 content[c.line][c.unit]을 사용하세요.

content_to_lines()

MiniStarter.content_to_lines({content})

하나의 버퍼 라인은 동일한 콘텐츠 라인 내의 단위들의 string 요소를 연결하여 만들어집니다.

매개변수

{content} (table|nil) 콘텐츠 “2차원 배열”. 기본값: 현재 버퍼의 콘텐츠.

반환

(table) 각 버퍼 라인에 대한 문자열 배열.

content_to_items()

MiniStarter.content_to_items({content})

콘텐츠를 항목으로 변환

콘텐츠를 (깊이 우선 방식으로) 파싱하고 유형이 “item”인 콘텐츠 단위의 item 요소에서 각 항목을 가져옵니다. 또한:

  • 항목이 실제로 어떻게 표시될지(MiniStarter.content_to_lines() 이후)에 대한 일부 헬퍼 정보와 특정 항목이 단독으로 쿼리되는 데 필요한 최소 접두사 문자 수를 계산합니다.

  • 콘텐츠 단위의 대응하는 string 요소를 가져와서 항목의 name 요소를 수정합니다. 이를 통해 콘텐츠 후크 단계(예: MiniStarter.gen_hook.indexing() 등)에서 항목의 name을 수정할 수 있습니다.

매개변수

{content} (table|nil) 콘텐츠 “2차원 배열”. 기본값: 현재 버퍼의 콘텐츠.

반환

(table) 항목 배열.
